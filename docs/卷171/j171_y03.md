==太建六年〔注:甲午、574年〕==

①春、正月、壬戌朔、周は斉公の宇文憲ら七人の爵を進めて王とした。

②己巳、周主が太廟を祀った。乙亥、藉田を耕した。

③壬子〔校勘注:十二行本などでは「子」を「午」に作る〕、上が太廟を祀った。

④甲申、広陵の金城が降った〔注:去年九月に樊毅が広陵の楚子城を陥したが、その金城はこのときになってようやく降ったのである〕。

⑤二月、壬午朔〔校勘注:孔本では「午」を「辰」に作る〕、日食があった。

⑥乙未、斉主が鄴に還った〔注:去年十月に晋陽へ行き、このときになってようやく還ったのである〕。

⑦乙酉、周は紀国公の賢ら六人の爵を進めて王とした。

⑧辛亥、上が藉田を耕した〔注:梁の初めは宋・斉に依って正月に行っていた。天監十二年、武帝は、啓蟄になって耕すものであり、『書経』にも「以て仲春を殷(ととの)う」とあるから、藉田は道理として建卯の月にあたるとして、二月に改めた。陳もこれに依って改めなかった〕。

⑨斉の朔州行台で南安王の高思好は、もと高氏の養子で、勇猛にして辺境の鎮の人心をつかんでいた。斉主が寵臣の斫骨光弁を州へ遣わしたが〔注:斫骨は胡族の複姓である〕、光弁が思好に礼を尽くさなかったので、思好は怒ってついに叛き、「入って君側の悪を除くのだ」と言った。軍を進めて陽曲に至り〔注:『五代志』:太原郡汾陽県は、旧名を陽曲という〕、みずから大丞相と号した。武衛将軍の趙海は晋陽にいたが〔校勘注:十二行本などでは「陽」の下に「掌兵(兵を掌る)」の二字がある〕、あわただしくて奏上する暇がなく、詔を偽って兵を発しこれを防いだ。帝は変事を聞いて、尚書令の唐邕らを晋陽へ急行させ〔注:「之」は「往く」の意である〕、辛丑、帝は兵を整えて後に続いて進んだ。まだ着かぬうちに、思好の軍は敗れ、思好は水に身を投げて死んだ。その配下の二千人を劉桃枝が囲み、殺しては降伏を呼びかけたが、最後まで降らず、全滅するに至った。

これより先、ある人が思好の謀反を告げたことがあった。韓長鸞は娘を思好の子に嫁がせていたので、こう奏上した——「この者は貴臣を誣告しております。殺さなければ後々を鎮められません」。そこでこれを斬った。思好が誅されたのち、告発した者の弟が宮門の下に伏して贈官を求めたが、長鸞は取り次いでやらなかった〔注:『通鑑』は、斉の寵臣どもが言路をふさいだ禍を言うのである〕。

丁未、斉主が鄴に還った。甲寅、唐邕を録尚書事とした。

⑩乙卯、周主が雲陽宮へ行った。

⑪丙辰、周が大赦した。

⑫庚申、周の叱奴太后が病気になった〔注:叱奴は胡族の複姓である〕。三月、辛酉、周主が長安に還った。癸酉、太后が亡くなった。帝は倚廬に居り〔注:陸徳明がいう——廬を東の壁に倚りかからせて作るので「倚廬」という。『考異』にいう——『隋書』張衡伝には「武帝が喪に居たとき、側近と出て狩りをしたので、衡は髪を振り乱し棺を輿に載せて切諫した」とある。しかし帝の居喪には礼があった。衡の自叙は妄りであろう〕、朝夕に一溢の米を進めるだけであった〔注:鄭玄は「二十両を溢という」という。粟米の法でいえば、一溢は米一升と二十四分の一升にあたる〕。群臣が上表して請うたので、幾旬も重ねてようやくこれをやめた。太子に命じて庶政を総べ治めさせた。

衛王の宇文直が斉王の宇文憲を帝に讒言して言った——「憲は酒を飲み肉を食って、いつもと変わりありません」。帝は言った——「わしと斉王とは母が違い〔注:「異生」とは母が違うことをいう〕、どちらも正嫡ではない。ただわしのゆえに、同じく肉袒して麻で髪を束ねているのだ〔注:「袒」は肌脱ぎ、「括」は結ぶこと。杜預は「麻で髪を束ねる」という〕。おまえこそ恥じ入るべきで、人の得失をあれこれ言う筋合いか。おまえは太后の実の子で、格別に慈愛を受けてきた。ただ自分を励めばよいので、他人のことをとやかく言うな」。

⑬夏、四月、乙卯、斉は侍中の薛孤康買を周へ遣わして弔問させ〔注:薛孤は胡族の複姓である〕、あわせて葬儀に参列させた。

はじめ、斉の世祖が胡后のために真珠の裙袴を造らせ、費えは数えきれないほどであったが、火に焼けてしまった。このとき、斉主はあらためて穆后のためにこれを作らせようとした。胡人の商人に錦や綵絹を三万持たせ、弔問の使者とともに行かせて真珠を買わせた。周人は売らなかったが、斉主はとうとう自前でこれを作らせた。穆后への寵愛が衰えると、その侍女の馮小憐が大いに寵愛され、淑妃に任ぜられた。斉主とは、座れば同じ席、出れば馬を並べ、生死をともにしようと誓い合った。

⑭五月、庚申、周は文宣皇后を永固陵に葬った。周主は裸足で歩いて陵所まで行った。辛酉、詔して言った——「三年の喪は天子にまで及ぶものである。ただ軍事・国政の務めが重く、自ら朝(ちょう)を聴かねばならない。衰(そい)と麻の作法、苫(とま)と廬(いおり)の礼は、おおむね前代の典礼に遵い〔注:『喪服小記』に「斬衰は麻で髪を束ね、苫に寝て廬に居る」とある〕、それによって限りない恩に報いたい〔注:『詩経』に「父よ我を生み、母よ我を育む。その徳に報いんとすれど、昊天きわまりなし」とある〕。百官は遺令に依り、葬儀が済んだら喪服を除くがよい」〔注:服を除くことである〕。公卿は権宜の制に依るよう固く請うたが、帝は許さず、ついに三年の制を貫いた。五服の親族についても、礼のとおりにさせた〔注:五服とは、斬衰の三年の服、斉衰の期年の服、大功の九月の服、小功の五月の服、緦麻の三月の服である〕。

⑮庚午、斉が大赦した。

⑯斉人は陳軍が淮を渡るのを恐れ、皮景和に西兗州へ屯させて備えさせた〔注:西兗州の治所は定陶である〕。

⑰丙子、周は仏・道の二教を禁じ、経典と像をことごとく毀ち〔注:「経」は二教の書、「像」は仏像と天尊像である〕、沙門・道士を廃してみな還俗させた。あわせて淫祀を禁じ、祀典に載っていないものはすべて除いた。

⑱六月、壬辰、周弘正が卒した。

⑲壬子、周はあらためて五行大布銭を鋳造した。一枚を十に当て、布泉と併せて通用させた〔注:布泉を行ったことは百六十八巻の世祖天嘉元年に見える〕。

⑳戊午、周は通道観を立てて、聖賢の教えを一つにまとめようとした。

㉑秋、七月、庚申、周主が雲陽へ行き、右宮正の尉遅運に司武を兼ねさせ〔注:『左伝』に宋の平公が「司武にして朝に梏(いまし)めらる」と言った。杜預の注に「司武は司馬のことである」という。周は六官を建てて、すでに大司馬があるから、司武はおそらくその属官であろう〕、薛公の長孫覧とともに太子を輔けて長安を守らせた。

はじめ、帝は衛王の宇文直の邸宅を取り上げて東宮とし〔注:建徳元年に太子を立て、はじめて東宮を建てた〕、直に自分で住む所を選ばせた。直は役所を次々に見て回ったが、気に入るものがなく、最後に廃寺となっていた陟屺寺を取って、そこに住もうとした〔注:陟屺寺は母を望むという意で名づけられた寺である。直は同母であることで周主の情を動かそうとしたのである〕。斉王の宇文憲が直に言った——「弟は子孫が多い。ここでは狭すぎるのではないか」。直は言った——「この身ひとつさえ容れてもらえぬのに、子孫のことなど言えようか」。

直はかつて帝に従って巻き狩りをしたとき、隊列を乱したので、帝は人々の前で彼を鞭打った。直は恨みと憤りを積み重ね、帝が都の外にいるのに乗じて、ついに乱を起こした。乙酉、その一党を率いて粛章門を襲った〔注:粛章は宮門の名である。唐の長安の太極宮では、太極殿の後ろ、両儀殿の前、中央が朱明門、東が虔化門、西が粛章門で、これは周の遺制であろう〕。長孫覧は恐れて、帝のいる所へ走った。尉遅運はたまたま門の中にいて、直の兵が突然やって来たので、自分の手で門を閉めた。直の一党が運と門を奪い合い、運の指を斬って傷つけたが、かろうじて閉めることができた。直は入れず、火を放って門を焼いた。運は、火が燃え尽きれば直の一党が入って来られると恐れ、宮中の材木や牀榻を取って火に足し、膏や油を注いだので、火はいよいよ盛んになった。長いあいだ直は進めず、そこで退いた。運は留守の兵を率い、直が退くのに乗じてこれを撃った。直は大敗し、百騎あまりを率いて荊州へ逃げた〔注:梁に身を寄せようとしたのである〕。戊子、帝が長安に還った。八月、辛卯、直を捕らえ、廃して庶人とし、別宮に閉じ込め、ほどなく殺した。尉遅運を大将軍とし、たいそう手厚く賜り物を与えた。

丙申、周主がふたたび雲陽へ行った。

㉒癸丑、斉主が晋陽へ行った。甲辰［寅］、斉は高勱を尚書右僕射とした。

㉓九月、庚申、周主が同州へ行った。

㉔冬、十月、丙申、周は御正で弘農の楊尚希と、礼部の盧愷を遣わして来聘させた〔注:武成元年に御正を四人に増やし、位は上大夫とした。保定四年には礼部を司宗と改め、大司礼を礼部と改めた。杜佑がいう——周の制では、礼部中大夫は春官に属する〕。愷は盧柔の子である〔注:盧柔は魏に仕えて中書監となった〕。

㉕甲寅、周主が蒲州へ行った。丙辰、同州へ行った。十一月、甲戌、長安に還った。

㉖十二月、戊戌、吏部尚書の王瑒を右僕射、度支尚書の孔奐を吏部尚書とした。瑒は王沖の子である。

そのころ淮・泗の地を回復したばかりで、攻め戦った功と、降って帰属した者への賞とが入り乱れていた〔注:攻め戦った者にはその功を記し、降って帰属した者にはその賞を記すのである〕。奐は人物を見る目が精確で機敏、口利きを受け付けず、事務が滞ることもなかったので、人はみな心服した。湘州刺史で始興王の陳叔陵は、たびたび担当の役所にほのめかして、三公になりたいと求めた。奐は言った——「袞の礼服を着る職は、もともと徳によって挙げるもので〔注:三公は一命の位である。「袞」は命服で、身につける章である〕、必ずしも皇族だからというものではありません」。そしてこれを帝に申し上げた。帝は言った——「始興がどうして急に公を望むのか。それに朕の子が公になるにしても、鄱陽王より後でなければならぬ」〔注:世祖の子が先に公になるべきだという意である〕。奐は言った——「臣の考えも、聖旨のとおりでございます」。

㉗斉の定州刺史で南陽王の高綽は、残虐なことをするのを好んだ〔注:この定州の治所は中山である〕。あるとき外出して、婦人が子を抱いているのを見ると、奪い取って犬に食わせた。婦人が声を上げて泣くと、綽は怒って、子の血を婦人に塗りつけ、犬を放って食わせた。いつもこう言っていた——「わしは文宣伯父の人となりを学んでいるのだ」。斉主はこれを聞き、鎖につないで行在所へ連行させたが、着くと赦した。そして尋ねた——「州にいて何が一番楽しかったか」。答えて言った——「器に蠍(さそり)をたくさん集め、その中に猿を入れて、見物するのがこのうえない楽しみでございました」。帝はさっそく命じて、夜のうちに蠍を一斗探させた。夜明けまでに二、三升が集まり、それを浴槽に入れ、人を裸にしてその中に寝かせると、叫び声を上げてのたうち回った。帝は綽とともに臨んで見物し、喜んで笑いが止まらなかった〔注:蠍は人を螫す虫で、淮から北にはこれがいる。『通俗文』に「尾の長いものを蠆、短いものを蠍という」とある。浴斛とは浴用の器である〕。そして綽を責めて言った——「これほど楽しいことを、どうして早馬で奏上して知らせなかったのだ」。これによって綽は寵を得、大将軍に任ぜられ、朝も晩も帝と一緒に遊び戯れた。韓長鸞はこれを憎み、この年、綽を斉州刺史として外へ出した。出発しようとするとき、人をやって謀反を誣告させ、こう奏上した——「これは国法を犯すもの、赦してはなりません」。帝は公然と誅するに忍びず、寵愛していた胡人の何猥薩に彼と素手で組み討ちをさせ、首を絞めて殺させた。

==六年==
春，正月，壬戌朔，周齊公憲等七人進爵爲王。
己巳，周主享太廟；乙亥，耕藉田。
壬子，上享太廟。
甲申，廣陵金城降。
二月，壬午朔，日有食之。
乙未，齊主還鄴。
乙酉，周紀國公賢等六人進爵爲王。
辛亥，上耕藉田。
齊朔州行臺南安王思好，本高氏養子，驍勇，得邊鎭人心。齊主使嬖臣斫骨光弁至州，光弁不禮於思好，思好怒，遂反，云「欲入除君側之惡」。進軍至陽曲，自號大丞相。武衞將軍趙海在晉陽，蒼猝不暇奏，矯詔發兵拒之。帝聞變，使尚書令唐邕等馳之晉陽，辛丑，帝勒兵繼進。未至，思好軍敗，投水死。其麾下二千人，劉桃枝圍之，且殺且招，終不降，以至於盡。
先是有人告思好謀反，韓長鸞女適思好子，奏言︰「是人誣告貴臣，不殺無以息後。」乃斬之。思好旣誅，告者弟伏闕下求贈官，長鸞不爲通。
丁未，齊主還鄴。甲寅，以唐邕爲錄尚書事。
乙卯，周主如雲陽宮。
丙辰，周大赦。
庚申，周叱奴太后有疾。三月，辛酉，周主還長安。癸酉，太后殂。帝居倚廬，朝夕進一溢米。羣臣表請，累旬乃止。命太子總釐庶政。
衞王直譖齊王憲於帝曰︰「憲飲酒食肉，無異平日。」帝曰︰「吾與齊王異生，俱非正嫡，特以吾故，同袒括髮。汝當愧之，何論得失！汝，親太后之子，特承慈愛；但當自勉，無論他人。」
夏，四月，乙卯，齊遣侍中薛孤康買弔於周，且會葬。
初，齊世祖爲胡后造珠裙袴，所費不可勝計；爲火所焚。至是，齊主復爲穆后營之。使商胡齎錦綵三萬，與弔使偕往市珠。周人不與，齊主竟自造之。及穆后愛衰，其侍婢馮小憐大幸，拜爲淑妃；與齊主坐則同席，出則並馬，誓同生死。
五月，庚申，周葬文宣皇后於永固陵；周主跣行至陵所。辛酉，詔曰︰「三年之喪，達於天子。但軍國務重，須自聽朝。衰麻之節，苫廬之禮，率遵前典，以申罔極。百僚宜依遺令，旣葬而除。」公卿固請依權制，帝不許，卒申三年之制。五服之內，亦令依禮。
庚午，齊大赦。
齊人恐陳師渡淮，使皮景和屯西兗州以備之。
丙子，周禁佛、道二敎，經、像悉毀，罷沙門、道士，並令還俗。幷禁諸淫祀，非祀典所載者盡除之。
六月，壬辰，周弘正卒。
壬子，周更鑄五行大布錢，一當十，與布泉並行。
戊午，周立通道觀以壹聖賢之敎。
㉑秋，七月，庚申，周主如雲陽，以右宮正尉遲運兼司武，與薛公長孫覽輔太子守長安。
初，帝取衞王直第爲東宮，使直自擇所居。直歷觀府署，無如意者；末取廢陟屺寺，欲居之。齊王憲謂直曰︰「弟子孫多，此無乃褊小？」直曰︰「一身尚不自容，何論子孫！」直嘗從帝校獵而亂行，帝對衆撻之，直積怨憤，因帝在外，遂作亂。乙酉，帥其黨襲肅章門。長孫覽懼，奔詣帝所。尉遲運偶在門中，直兵奄至，手自闔門。直黨與運爭門，斫傷運指，僅而得閉。直不得入，縱火焚門。運恐火盡，直黨得進，取宮中材木及牀榻以益火，膏油灌之，火轉熾。久之，直不得進，乃退。運帥留守兵，因其退而擊之，直大敗，帥百餘騎奔荊州。戊子，帝還長安。八月，辛卯，擒直，廢爲庶人，囚於別宮，尋殺之。以尉遲運爲大將軍，賜賚甚厚。
丙申，周主復如雲陽。
㉒癸丑，齊主如晉陽。甲辰［寅］，齊以高勱爲尚書右僕射。
㉓九月，庚申，周主如同州。
㉔冬，十月，丙申，周遣御正弘農楊尚希、禮部盧愷來聘。愷，柔之子也。
㉕甲寅，周主如蒲州；丙辰，如同州；十一月，甲戌，還長安。
㉖十二月，戊戌，以吏部尚書王瑒爲右僕射，度支尚書孔奐爲吏部尚書。瑒，沖之子也。
時新復淮、泗，攻戰、降附，功賞紛紜。奐識鑒精敏，不受請託，事無凝滯，人皆悅服。湘州刺史始興王叔陵，屢諷有司，求爲三公。奐曰︰「袞章之職，本以德舉，未必皇枝。」因以白帝。帝曰︰「始興那忽望公！且朕兒爲公，須在鄱陽王後。」奐曰︰「臣之所見，亦如聖旨。」
㉗齊定州刺史南陽王綽，喜爲殘虐，嘗出行，見婦人抱兒，奪以飼狗。婦人號哭，綽怒，以兒血塗婦人，縱狗使食之。常云︰「我學文宣伯之爲人。」齊主聞之，鎖詣行在，至而宥之。問︰「在州何事最樂？」對曰︰「多聚蠍於器，置狙其中，觀之極樂。」帝卽命夜索蠍一斗，比曉，得三二升，置浴斛，使人裸臥斛中，號叫宛轉。帝與綽臨觀，喜噱不已。因讓綽曰︰「如此樂事，何不馳驛奏聞！」由是有寵，拜大將軍，朝夕同戲。韓長鸞疾之，是歲，出爲齊州刺史。將發，使人誣告其反，奏云︰「此犯國法，不可赦！」帝不忍明誅，使寵胡何猥薩與之手搏，搤而殺之。
