==元和八年〔注:癸巳、813年〕==

①春、正月、癸亥、博州刺史の田融を相州刺史とした。融は興の兄である。融と興は幼くして父母を失い、融のほうが年上だったので、弟を養い育てて教えた〔注:兄弟はともに幼くして父母を失ったが、兄の年がいくらか上だったので、弟を養い育てて教えたのである〕。興がかつて軍中で射を競い〔注:角は競うこと。角射とは的に中てた者を勝ちとするものである〕、一軍に及ぶ者がなかったことがある。融は退出してから興を打って言った——「お前が自分を目立たぬようにしなければ、禍が及ぶぞ」。だから興は、疑い深く残虐な主のもとでも身を全うできたのである〔注:猜暴の時とは、田季安の時を言う〕。

②勃海の定王・元瑜が卒し、弟の言義が国務を代行した。庚午、言義を勃海王とした。

③李吉甫と李絳はたびたび上の前で論じ争ったが、前礼部尚書・同平章事の権德輿はその間にいて可とも否とも言わなかった。上はこれを見下した。辛未、德輿は宰相を罷めて本官のみを守ることになった。

④辛卯、魏博節度使の田興に弘正の名を賜った。

⑤司空・同平章事の于頔は長く長安に留まり、鬱々として志を得ずにいた〔注:元和二年に頔が入朝したことは二百三十二巻に見える〕。梁正言という者がいて、自分は樞密使の梁守謙と同族で、人のために願いを取り次げると言った。頔は子の太常丞の敏に、正言へ厚く賄賂を贈らせ、地方の鎮に出してもらうよう求めた。しばらくして正言の偽りがしだいに露見し、敏はその賄賂を取り戻そうとしたが果たせず、正言の下僕を誘い出して手足を切り裂き、厠に棄てた。事が発覚し、頔は子の殿中少監の季友らを率い、素服で建福門に出向いて罪を請うたが、門番は入れなかった〔注:唐の大明宮の端門を丹鳳門といい、その西を建福門という〕。退いて南の塀を背に立ち、人を遣わして表を差し出そうとしたが、閤門は印もなく内引もないとして受け取らなかった〔注:唐の制度では、四方からの章表はすべて閤門が受けて取り次ぐ。頔はいま罪を請う身で、職印もなく、内引もなかったので受け取られなかったのである〕。日暮れになってようやく帰り、翌日また出向いた。丁酉、頔を恩王傅に落とし、なお朝謁を禁じた。敏は雷州に流され〔注:『旧志』によれば、雷州は京師から六千五百十二里〕、季友らはみな官を貶され、僮僕で死んだ者が数人あった。敏は秦嶺まで来て死んだ〔注:藍田関から南へ出て秦嶺を越える〕。

この事件は僧の鑒虚に連なった。鑒虚は貞元年間以来、財で権勢家や寵臣と交わり、地方の藩鎮からの贈り物を受け取り、身を厚く養っていたが、官吏も咎めることができなかった。ここに至って権勢家や寵臣が争って彼のために口添えし、上も釈放しようとしたが、御史中丞の薛存誠が承知しなかった。上は中使を御史台へ遣わして旨を伝えさせた——「朕はこの僧に直接問い質したいのだ。釈すのではない」。存誠は答えた——「陛下がどうしてもこの僧を面前で釈されるおつもりなら、まず臣を殺してからお引き取りください。さもなければ、臣は詔を奉じません」。上はこれを嘉して従った。三月、丙辰、鑒虚を杖で打ち殺し、その所有する財産を没収した。

⑥甲子、前の西川節度使・同平章事の武元衡を召し寄せて政事を執らせた〔注:元和二年に武元衡は西川へ出鎮し、ここに至って召し返された〕。

⑦夏、六月、大水があった。上はこれを陰の気が満ちる兆しと考え、辛丑、宮人を二百車ぶん宮外へ出した。

⑧秋、七月、振武節度使の李光進が、受降城の修築と、あわせて河の防備の管理を請うた。当時、受降城は河に壊されていた〔注:河が受降城を壊したことは前巻の七年に見える〕。李吉甫はその人々を天德の故城へ移すよう請うたが〔注:天德の故城は東受降城の西二百里、大同川にある。乾元以後、天德軍を永濟栅へ移した。宋白の『続通典』は「永清栅」に作る。その城は隋の大同城の旧跡である〕、李絳と戶部侍郎の盧坦は、こう考えた——「受降城は張仁愿が築いたもので〔注:このことは二百九巻・中宗の景龍元年に見える〕、磧口に当たり、敵の要衝を押さえ、水も草もよく、辺境を守るのに有利な地です。いま河の害を避けるなら、二、三里退けば足ります。どうして万代永安の策を捨てて、一時の費用節約の便に従うのですか。まして天德の故城は僻地で土地が痩せ、河から遠く離れ、烽火の急報も互いに応接できません。敵が不意に襲ってきても、知りようがない。これは理由もなく国土を二百里縮めることです」。城使の周懷義が奏上した利害の見立ても、絳・坦と同じであった。上は結局、吉甫の策を用い、受降城の騎士を天德軍に隷属させた。

李絳が上に言った——「辺境の軍は数だけあって実がなく、いたずらに衣糧を費やしております。将帥はただ公の役目にかこつけて私用に使い〔注:縁私とは、公の役という名にかこつけて私用に使うことである〕、財貨を集めて権勢家や寵臣と結ぶだけで、不測の事態に備えて訓練したことがありません。これは事のない時にこそ、あらかじめお心に留めておかねばならぬことです」。当時、受降城の兵籍はもと四百人であったが、天德軍へ引き渡すときには五十人しかおらず、武具は弓が一張あるだけで、他もこれに準じていた。それゆえ絳がこの話に及んだのである。上は驚いて言った——「辺境の兵はそこまで空っぽなのか。卿らは点検を加えよ」。ちょうど絳が宰相を罷めたので、沙汰止みとなった。

⑨乙巳、天威軍を廃し、その兵を神策軍に隷属させた〔注:元和のはじめ、左右の神威を合わせて一軍とし、天威軍と号した。神威軍はもと殿前射生軍である〕。

⑩丁未、辰州・潊州の賊帥である張伯靖が降伏を願い出た〔注:辰・潊の賊が反したことは前巻の六年に始まる〕。辛亥、伯靖を歸州司馬とし、荊南の軍前駆使に付けた。

⑪はじめ、吐蕃は烏蘭橋を架けようとして、先に材木を河のほとりに貯えていた〔注:『新志』によれば、會州の烏蘭県に烏蘭関があり、県の西南にある。吐蕃は河の上に橋を架けた〕。朔方はいつもひそかに人を遣わしてそれを河へ投げ込ませたので、ついに完成しなかった。敵は朔方・靈鹽節度使の王佖が欲深いと知り、先に厚く賄賂を贈り、そのうえで力を合わせて橋を完成させ、さらに月城を築いて守った。これより朔方は敵を防ぐのに手一杯となった。

⑫冬、十月、回鶻が兵を出して磧を南へ渡り、柳谷から西へ向かって吐蕃を撃った〔注:『新志』によれば、西州の交河県の北二百十里に、柳谷を経る渡しがある〕。壬寅、振武・天德軍が、回鶻の数千騎が鸊鵜泉まで来たと奏上し〔注:鸊鵜泉は西受降城の北三百里にある〕、辺境の軍は戒厳態勢をとった。

⑬振武節度使の李進賢は士卒をいたわらなかった。判官の嚴澈は綬の子で〔注:このとき嚴綬はまだ存命であった〕、細かく厳しく取り調べることで進賢に気に入られていた。進賢は牙将の楊遵憲に五百騎を率いて東受降城へ急行させ、回鶻に備えさせたが、支給するはずの装備の多くは、現物を渡さず値だけを偽って別の物で代えていた〔注:装備を現物で支給せず、値だけを見積もって別の物で支給したのである〕。鳴沙まで来ると、遵憲は家屋の中に泊まり、士卒は野ざらしであった。衆は怒り、夜、薪を集めてその家を取り囲んで焼き、甲を巻いて引き返した。庚寅の夜、門を焼いて進賢を攻めた。進賢は城を越えて逃げ、軍士はその一家を殺し、あわせて嚴澈も殺した。進賢は靜邊軍へ奔った〔注:靜邊軍は雲州の西百八十里にある〕。

⑭群臣がたびたび表を上げ、德妃の郭氏を皇后に立てるよう請うた。上は妃の一門が強く盛んなので〔注:妃は郭曖の娘、郭子儀の孫娘である〕、正妻の位についたあとは後宮の誰も上に近づけなくなるのを恐れ、季節の禁忌にかこつけて、ついに許さなかった。

⑮丁酉、振武の監軍である駱朝寬が、乱れた兵はすでに鎮まったと奏上し、将士に衣を支給するよう請うた。上は怒り、夏綏節度使の張煦を振武節度使とし、夏州の兵二千を率いて任地へ赴かせ、さらに河東節度使の王鍔に兵二千でこれを送り込ませ、臨機の処置を許した。駱朝寬は罪をその配下の将である蘇若方になすりつけて殺した。

⑯鄭滑・魏博の兵を出して、黎陽の古い河道十四里を掘り、滑州の水害を和らげた〔注:黄河の旧い流れは黎陽山の東を通っていたが、後に南へ移り、滑州の害となった。それゆえ古い河道を掘り直したのである〕。

⑰上が宰相に問うた——「世間では、外で朋党が大いに盛んだと言う。どういうことか」。李絳が答えた——「古来、人君がひどく憎むものとして、臣下が朋党を組むことに勝るものはありません。だから小人が君子を讒するときは、必ず朋党と言うのです。なぜか。朋党と言えば憎まれるうえ、追及しても跡が残らないからです。後漢の末、天下の賢人君子をすべて宦官は党人と呼んで禁錮し、ついに国を亡ぼしました〔注:漢の桓帝紀・霊帝紀に見える〕。これはみな、小人どもが善人を害そうとして使う言葉です。どうか陛下、深くお察しください。そもそも君子はもとより君子と合うもの。どうして必ず小人と合わせてみせなければ、党ではないと言えないのでしょうか」。

八年
春，正月，癸亥，以博州刺史田融爲相州刺史。融，興之兄也。融、興幼孤；融長，養而敎之。興嘗於軍中角射，一軍莫及。融退而抶之曰︰「爾不自晦，禍將及矣！」故興能自全於猜暴之時。
勃海定王元瑜卒，弟言義權知國務。庚午，以言義爲勃海王。
李吉甫、李絳數爭論於上，前禮部尚書、同平章事權德輿居中無所可否；上鄙之。辛未，德輿罷守本官。
辛卯，賜魏博節度使田興名弘正。
司空、同平章事于頔久留長安，鬱鬱不得志。有梁正言者，自言與樞密使梁守謙同宗，能爲人屬請，頔使其子太常丞敏重賂正言，求出鎭。久之，正言詐漸露，敏索其賂不得，誘其奴，支解之，棄溷中。事覺，頔帥其子殿中少監季友等素服詣建福門請罪，門者不內；退，負南牆而立，遣人上表，閤門以無印引不受；日暮方歸，明日，復至。丁酉，頔左授恩王傅，仍絕朝謁；敏流雷州，季友等皆貶官，僮奴死者數人；敏至秦嶺而死。
事連僧鑒虛。鑒虛自貞元以來，以財交權倖，受方鎭賂遺，厚自奉養，吏不敢詰。至是，權倖爭爲之言，上欲釋之，中丞薛存誠不可。上遣中使詣臺宣旨曰︰「朕欲面詰此僧，非釋之也。」存誠對曰︰「陛下必欲面釋此僧，請先殺臣，然後取之，不然，臣期不奉詔。」上嘉而從也。三月，丙辰，杖殺鑒虛，沒其所有之財。
甲子，徵前西川節度使、同平章事武元衡入知政事。
夏，六月，大水。上以爲陰盈之象，辛丑，出宮人二百車。
秋，七月，振武節度使李光進請脩受降城，兼理河防。時受降城爲河所毀，李吉甫請徙其徒於天德故城，李絳及戶部侍郎盧坦以爲︰「受降城，張仁愿所築，當磧口，據虜要衝，美水草，守邊之利地。今避河患，退二三里可矣，柰何捨萬代永安之策，徇一時省費之便乎！況天德故城僻處确瘠，去河絕遠，烽候警急不相應接，虜忽唐突，勢無由知，是無故而蹙國二百里也。」及城使周懷義奏利害，與絳、坦同。上卒用吉甫策，以受降城騎士隸天德軍。
李絳言於上曰︰「邊軍徒有其數而無其實，虛費衣糧，將帥但緣私役使，聚貨財以結權倖而已，未嘗訓練以備不虞，此不可不於無事之時預留聖意也。」時受降城兵籍舊四百人，及天德軍交兵，止有五十人，器械止有一弓，自餘稱是。故絳言及之。上驚曰︰「邊兵乃如是其虛邪！卿曹當加按閱。」會絳罷相而止。
乙巳，廢天威軍，以其衆隸神策軍。
丁未，辰、潊賊帥張伯靖請降。辛亥，以伯靖爲歸州司馬，委荊南軍前驅使。
初，吐蕃欲作烏蘭橋，先貯材於河側，朔方常潛遣人投之於河，終不能成。虜知朔方、靈鹽節度使王佖貪，先厚賂之，然後倂力成橋，仍築月城守之。自是朔方禦寇不暇。
冬，十月，回鶻發兵度磧南，自柳谷西擊吐蕃。壬寅，振武、天德軍奏回鶻數千騎至鸊鵜泉，邊軍戒嚴。
振武節度使李進賢，不恤士卒；判官嚴澈，綬之子也，以刻覈得幸於進賢。進賢使牙將楊遵憲將五百騎趣東受降城以備回鶻，所給資裝多虛估；至鳴沙，遵憲屋處而士卒暴露；衆發怒，夜，聚薪環其屋而焚之，卷甲而還。庚寅夜，焚門，攻進賢，進賢踰城走，軍士屠其家，幷殺嚴澈。進賢奔靜邊軍。
羣臣累表請立德妃郭氏爲皇后。上以妃門宗強盛，恐正位之後，後宮莫得進，託以歲時禁忌，竟不許。
丁酉，振武監軍駱朝寬奏亂兵已定，請給將士衣。上怒，以夏綏節度使張煦爲振武節度使，將夏州兵二千赴鎭，仍命河東節度使王鍔以兵二千納之，聽以便宜從事。駱朝寬歸罪於其將蘇若方殺之。
發鄭滑、魏博卒鑿黎陽古河十四里，以紓滑州水患。
上問宰相︰「人言外間朋黨大盛，何也？」李絳對曰︰「自古人君所甚惡者，莫若人臣爲朋黨，故小人譖君子必曰朋黨。何則？朋黨言之則可惡，尋之則無跡故也。東漢之末，凡天下賢人君子，宦官皆謂之黨人而禁錮之，遂以亡國。此皆羣小欲害善人之言，願陛下深察之！夫君子固與君子合，豈可必使之與小人合，然後謂之非黨邪！」
