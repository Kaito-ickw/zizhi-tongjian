# 卷233 唐紀四十九 — 德宗神武聖文皇帝八七年

> 巻 233 / 294 ・ 唐紀四十九 ・ 年号: 德宗神武聖文皇帝八七年 ・ 西暦: 791 CE

[← 巻インデックス](README.md)

①春、正月、己巳、襄王の李僙が薨じた〔注:僙は粛宗の子である〕。

②二月、癸卯、鴻臚少卿の庾鋋を遣わして回鶻の奉誠可汗を册立させた〔注:『考異』にいう。『実録』は「康鋋」に作るが、今は『新伝』『旧伝』に従う〕。

③戊戌、詔して涇原節度使の劉昌に平涼の古城を築かせ〔注:『旧書』にいう。城は原州から百五十里の距離にある〕、弾箏峡の入口を押さえさせた。十二日で完成し〔注:「浹」は『周礼』の「挾日而斂」の「挾」と同じ。鄭氏の注に、甲から甲までを挾という、とある。ここに浹辰というのは、子から子までのことである。史炤がいう。子から亥までを辰という。浹辰とは十二日である〕、兵を分けてこれを守らせた。昌はまた朝谷堡を築いた〔注:『旧唐書』は「胡谷堡」に作る。東は平涼から三十五里の距離にある〕。甲子、詔してその堡を彰信と名づけた〔注:『旧書』は「彰義」に作る〕。涇原はいくらか安らかになった。

④はじめ、上が長安に還ったとき、神策などの軍に護衛随従の労があったので、みなに「興元元従奉天定難功臣」の名を賜い〔注:宋白がいう。唐の玄宗が内乱を平定したとき、衛士の葛福順らに唐元功臣の名を賜ったが、十数人にすぎなかった。徳宗が奉天に留まり山南へ行幸したときは、供奉して功を立てた将校に元従奉天定難功臣の名を賜った。谷口からこのかたは、元従の将士に元従功臣の名を賜った。僖宗・昭宗の代になって毎年のように都落ちすると、功臣はいよいよ増えた。後梁・後唐に至っては一般の兵卒にまで行きわたり、もはや褒賞の典ではなくなった〕、官職をもってこれを統率させ、手厚くいたわった。禁軍は恩を笠に着て驕り高ぶり、百姓を侵し虐げ、京兆府や県の役所を侮り、役人を罵り辱め、公文書を破り裂くまでになった〔注:「府」は京兆府をいう。「県」は赤県・畿県をいう〕。府や県の役人で怒りに耐えかねてこれを処罰する者があると、朝に一人を笞打てば夕には万里の彼方に左遷された。そのため府県に公正で厳格な官がいても、その職務を果たすことができなかった。町の富民はしばしば賄賂を使って軍籍に名を寄せ、そうなると府県は手を出せなかった。辛巳、詔した——「神威・六軍の吏士と百姓とが訴訟になったときは、府県に委ねる。小さな事は本軍に文書で通知し、大きな事は奏上せよ。もし軍士が府県を侮り軽んじたら、身柄を拘禁したうえで奏聞し、御史台に取り調べさせよ。県の役人がみだりに笞打ち辱めたときは、必ず貶謫に処する」〔注:北軍の十軍とは、左・右の羽林、龍武、神武、神威、神策であり、神策がとりわけ盛んであった。建中より前は左右の軍に分かれていなかった。神策六軍というのは、神策軍と左・右の羽林、龍武、神武の六軍を指していう。貞元二年、神策の左・右廂を左・右神策軍とし、また殿前射生の左・右廂を左・右射生軍とした。四年、左・右射生軍を左・右神威軍とした。北軍はこうして十軍となった。このとき神策軍はすでに北軍の首位にあり、史家がこの事を書くにあたって、もっぱら神策が恩を恃んで人を虐げたためにこの詔が出たと言うのだから、いわゆる「神威六軍」もまた「神策・六軍」であるはずで、「威」の字は誤りである。この神策・六軍とは、左・右神策軍を挙げたうえで左・右の龍武、神武、神威の六軍を指す。左・右羽林軍に及ばないのは、羽林が唐初に置かれたのに対し、龍武などの軍はみな開元以来おいおい禁衛に増置され、しかも羽林より天子に近しかったからである。「禁身」とは、その身柄を拘禁することである〕。

⑤癸未、易定節度使の張孝忠が薨じた。

⑥安南都護の高正平が重く税を取り立てたので〔注:安南都護府はもと交州で、調露二年に安南都護府として置かれた〕、夏、四月、諸蛮の酋長の杜英翰らが兵を起こして都護府を囲んだ。正平は憂いのうちに死に、諸蛮はこれを聞いてみな降った〔注:蛮は乱を好むのではなく、貪欲な長官に苦しんで乱れるのだ、と史は言っている〕。五月、辛巳、柔遠軍を安南に置いた。

⑦端王の李遇が薨じた〔注:遇は皇帝の弟である〕。

⑧韋皋はここ数年、書状を送って雲南王の異牟尋を招いていたが〔注:韋皋が書状で雲南を招いた事は前巻の三年に始まる〕、ついに返事を得られなかった。しかし吐蕃が雲南の兵を徴発するたび、雲南が出す兵はますます少なくなっていた。皋は異牟尋の心が唐に寄っていることを知った。討撃副使の段忠義は、もともと閤羅鳳の使者であった〔注:閤羅鳳は異牟尋の祖父である〕。六月、丙申、皋は忠義を雲南へ帰し、あわせて書状を届けて強く諭させた。

⑨秋、七月、戊寅、定州刺史の張昇雲を義武留後とした。

⑩庚辰、虔州刺史の趙昌を安南都護とし、諸蛮はそれで落ち着いた。

⑪八月、丙午、翰林学士の陸贄を兵部侍郎とし、ほかの職はみな解いた。竇参が彼を憎んだのである。

⑫吐蕃が霊州を攻めたが、回鶻に敗れ、夜のうちに逃げた。九月、回鶻は使者を遣わして捕虜を献じ、冬、十二月、甲午、また使者を遣わして捕らえた吐蕃の酋長の尚結心を献じた。

⑬福建観察使の呉湊は治績で評判が高かったが〔注:福建はみな古い閩越の地である。秦は閩中郡とし、漢は冶県、後漢は候官県とした。呉は建安郡を置き、陳は閩州を置いた。隋は泉州と改めた。唐は泉州を晋江県に移し、閩州は閩県と候官県を治所とし、建安県に建州を立てた。建安は呉の孫策が置いた県で、年号を県名とした。もとはやはり東の候官の地である。開元十三年、また閩州を福州と改めた。これより福・建・泉の三州がはじめて混同されなくなった〕、竇参が私怨からこれをそしり、そのうえ彼は中風を病んでいると言った。上は湊を京師へ召し、歩かせてこれを確かめ、参の讒言だと知って、これより参を憎み始めた〔注:竇参が貶されて追われることの伏線である〕。丁酉、湊を陝虢観察使として、参の一味である李翼と交代させた。

⑭睦王の李述が薨じた〔注:述もまた皇帝の弟である〕。

⑮吐蕃は韋皋の使者が雲南にいることを知り、使者を遣わして雲南を責めた。雲南王の異牟尋は「唐の使者というが、もとは蛮の者だ。皋はその帰国を許しただけで、ほかに謀りごとはない」といつわって言い、そのうえで彼を捕らえて吐蕃に送った。吐蕃は雲南の大臣の子を多く取って人質としたので、雲南はますます怨んだ。

勿鄧の酋長の苴夢衝がひそかに吐蕃と通じ、諸蛮を煽り誘って、雲南の使者の往来を遮った。韋皋は三部落総管の蘇峞を遣わし、兵を率いて琵琶川へ至らせた〔注:三部落とは両林・勿鄧・豊琶である。琵琶川は巂州の西南、境の外にある〕。

七年
春，正月，己巳，襄王僙薨。
二月，癸卯，遣鴻臚少卿庾鋋册回鶻奉誠可汗。
戊戌，詔涇原節度使劉昌築平涼故城，以扼彈箏峽口；浹辰而畢，分兵戍之。昌又築朝谷堡；甲子，詔名其堡曰彰信；涇原稍安。
初，上還長安，以神策等軍有衞從之勞，皆賜名興元元從奉天定難功臣，以官領之，撫恤優厚。禁軍恃恩驕橫，侵暴百姓，陵忽府縣，至詬辱官吏，毀裂案牘。府縣官有不勝忿而刑之者，朝笞一人，夕貶萬里，由是府縣雖有公嚴之官，莫得舉其職。市井富民，往往行賂寄名軍籍，則府縣不能制。辛巳，詔︰「神威、六軍吏士與百姓訟者，委之府縣，小事牒本軍，大事奏聞。若軍士陵忽府縣，禁身以聞，委御史臺推覆。縣吏輒敢笞辱，必從貶謫。」
癸未，易定節度使張孝忠薨。
安南都護高正平重賦斂，夏，四月，羣蠻酋長杜英翰等起兵圍都護府，正平以憂死，羣蠻聞之皆降。五月，辛巳，置柔遠軍於安南。
端王遇薨。
韋皋比年致書招雲南王異牟尋，終未獲報。然吐蕃每發雲南兵，雲南與之益少。皋知異牟尋心附於唐，討擊副使段忠義，本閤羅鳳使者也，六月，丙申，皋遣忠義還雲南，幷致書敦諭之。
秋，七月，戊寅，以定州刺史張昇雲爲義武留後。
庚辰，以虔州刺史趙昌爲安南都護，羣蠻遂安。
八月，丙午，以翰林學士陸贄爲兵部侍郎，餘職皆解；竇參惡之也。
吐蕃攻靈州，爲回鶻所敗，夜遁。九月，回鶻遣使來獻俘；冬，十二月，甲午，又遣使獻所獲吐蕃酋長尚結心。
福建觀察使吳湊，爲治有聲，竇參以私憾毀之，且言其病風；上召至京師，使之步以察之，知參之誣，由是始惡參。丁酉，以湊爲陝虢觀察使以代參黨李翼。
睦王述薨。
吐蕃知韋皋使者在雲南，遣使讓之。雲南王異牟尋紿之曰︰「唐使，本蠻也，皋聽其歸耳，無他謀也。」因執以送吐蕃。吐蕃多取其大臣之子爲質，雲南愈怨。
勿鄧酋長苴夢衝，潛通吐蕃，扇誘羣蠻，隔絕雲南使者。韋皋遣三部落總管蘇峞將兵至琵琶川。
