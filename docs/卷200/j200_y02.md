==顕慶元年〔注:丙辰、656年〕==

①春、正月、辛未、皇太子の忠を梁王・梁州刺史とし、皇后の子である代王弘を皇太子に立てた。生まれて四年になっていた。忠が廃されると、その官属はみな罪を恐れて逃げ隠れ、あえて会いに来る者もなかったが、右庶子の李安仁だけは忠に伺候し、涙を流して拝礼し別れを告げて去った。安仁は李綱の孫である〔注:李綱は隋から唐にかけて節操で知られた〕。

②壬申、天下に大赦し、改元した。

③二月、辛亥、武士彠に司徒を贈り、周国公の爵を賜った。

④三月、度支侍郎の杜正倫を黄門侍郎・同三品とした〔注:顕慶元年、戸部を度支と改めた〕。

⑤夏、四月、壬子、矩州の人である謝無霊が兵を挙げて反いたので〔注:矩州の諸蛮もまた東謝蛮の一族である。武徳四年に矩州を置いた〕、黔州都督の李子和が討ち平らげた。

⑥己未、高宗が侍臣に言った——「朕は民を養う道を思うが、その要をつかめないでいる。公らは朕のために述べてくれ」。来済が答えた——「むかし斉の桓公が出遊して、老いて飢え凍えている者を見かけ、食を賜るよう命じました。老人は『どうか国じゅうの飢えた者に賜ってください』と言いました。衣を賜ろうとすると、『どうか国じゅうの凍えた者に賜ってください』と言いました。公が『わしの倉や府庫だけで、どうして一国の飢えと寒さを賄えようか』と言うと、老人は『君主が農時を奪わなければ、国じゅうの民に食が余ります。蚕の時期を奪わなければ、国じゅうの民に衣が余ります』と言いました。ですから人君が民を養うということは、その徴発と労役を減らすことに尽きるのです。いま山東の役丁は、年ごとに数万にのぼります。人を使役すれば民は大いに疲れ、庸(代納の銭布)を取れば民は大いに費えます。臣は願わくは、陛下が官の入り用の分を量ったうえで、残りはすべて免除なさいますよう」。高宗はこれに従った。

⑦六月、辛亥、礼官が、太祖と世祖の配祀をやめ〔注:高祖が禅譲を受けたとき、祖父の李虎を追尊して景皇帝とし、廟号を太祖といい、父の李昺を元皇帝とし、廟号を世祖といった〕、高祖を円丘で昊天に配し、太宗を明堂で五帝に配することを奏上した〔注:武徳の初め、円丘の壇を明徳門の外、道の東二里に立てた。壇の造りは四段で、各段の広さは八尺一寸、下の段は広さ二十丈、二段目は十五丈、三段目は十丈、四段目は五丈。祀るたびに、昊天上帝および配帝の位を平座に設け、敷物には藁秸を用い、器には陶器と匏を用いた。五方上帝・日月・内官・中官・外官および衆星は、みな従祀した。その五方帝と日月の七座は壇の第二段の内にあり、五星以下の官五十五座は壇の第三段に、二十八宿以下の官百三十五座は壇の第四段に、外官百二十二座は壇の下の外壝の内に、衆星三百六十座は外壝の外にあった。景帝を円丘に配し、元帝を明堂に配した〕。これに従った。

⑧秋、七月、乙丑、西洱蛮の酋長である楊棟附、顕和蛮の酋長である王郎祁〔注:【章:十二行本では「郎」を「羅」に作る。乙十一行本も同じ】〕、郎・昆・棃・盤の四州の酋長である王伽衝らが、それぞれ衆を率いて内附した〔注:黎州はもと西寧州で、武徳七年に南寧州の二県を分けて置き、貞観八年に黎州と改名した。その地は北で昆州に接し、晋の梁水郡の地である。盤州はもと西平州で、武徳四年に置き、貞観八年に改名した。晋の興古郡の地である〕。

⑨癸未、中書令の崔敦礼を太子少師・同中書門下三品とした。八月、丙申、固安昭公の崔敦礼が薨じた〔注:『諡法』に、容儀が恭しく美しいのを昭といい、徳を明らかにして功労があるのを昭という〕。

⑩辛丑、葱山道行軍総管の程知節が西突厥を撃ち、歌邏〔注:【章:十二行本では「邏」の下に「祿」の字がある。乙十一行本も同じ。孔本も同じ。退斎校も同じ】〕・処月の二部と楡慕谷で戦って〔注:処月・処密・姑蘇・歌邏祿・弩失畢の五姓の衆は、賀魯が葉護であったときに統べていたものである。『新書』によれば、歌邏祿はすなわち葛邏祿である。「楡慕谷」を『旧書』本紀は「楡幕谷」に作る〕、これを大いに破り、千余級を斬った。副総管の周智度は突騎施・処木昆らの部を咽城で攻めてこれを抜き〔注:西突厥の咄陸五啜のうち、処木昆と突騎施はいずれも一啜である。『新書』によれば、咽城は処木昆の居るところである〕、三万級を斬った。

⑪乙巳、亀茲王の布失畢が入朝した。

⑫李義府は寵愛を恃んで権をふるった。洛州の婦人である淳于氏は美しく、大理の獄につながれていたが、義府は大理寺丞の畢正義に言いつけて法を曲げて出させ、妾に迎えようとした。大理卿の段宝玄が怪しんで奏上したので、高宗は給事中の劉仁軌らに命じて取り調べさせた。義府は事が漏れるのを恐れ、正義に迫って獄中で首をくくらせた。高宗はこれを知りながら、義府の罪を許して問わなかった。

侍御史で漣水の人である王義方が、これを弾劾しようとして〔注:漣水はもと襄賁といい、東海郡が置かれた。東魏は海安郡と改めた。隋の開皇の初めに郡を廃し、襄賁を漣水と改めて海州に属させ、唐では泗水に属した〕、まず母に打ち明けて言った——「義方は御史の職にあります。奸臣を見ながら糾さなければ不忠、糾せば身が危うくなり心配が親にまで及んで不孝。二つのどちらにも決めかねます。どうしましょう」。母は言った——「むかし王陵の母は、身を殺して子の名を成し遂げさせました〔注:このことは九巻、漢の高帝元年に見える〕。おまえが忠を尽くして君に仕えられるなら、わたしは死んでも恨みはありません」。そこで義方は奏上した——「義府は天子のお膝元で、ほしいままに六品の寺丞を殺しました〔注:『唐六典』によれば、大理寺丞は従六品上〕。よし正義が自殺したというにしても、それも義府の威を畏れ、身を殺して口を封じたのです。このようでは、生殺の威が主上から出ないことになります。この兆しを伸ばしてはなりません。どうかあらためて取り調べを加えてください」。そこで儀仗を前にした朝廷で、義府を叱って階を下りるよう命じたが、義府はあたりをうかがって退かなかった。義方が三度叱っても、高宗が何も言わないでいると、義府はようやく小走りに出ていった。そこで義方は弾劾文を読み上げた。高宗は義府を放免して問わず、かえって義方が大臣を辱め、言葉が不遜であるとして、萊州司戸に左遷した。

⑬九月〔注:【章:十二行本では「月」の下に「庚辰」の二字がある。乙十一行本も同じ】〕、括州で暴風が吹き、海があふれて、四千余家が水に呑まれた〔注:『新志』によれば、処州はもと括州永嘉郡で、当時は永嘉の地も兼ねていた。上元元年になって初めて分けて温州を置いた〕。

⑭冬、十一月、丙寅、生羌の酋長である浪我利波らが衆を率いて内附したので、その地に柘・栱の二州を置いた〔注:柘州は蓬山郡。栱州は鉢南伏浪恐部をもとに置いた。どちらも松州都督府に属する。宋白がいう——柘州は開拓するという意味で名づけた〕。

⑮十二月、程知節が軍を率いて鷹娑川に至り、西突厥の二万騎に出くわした。別部の鼠尼施らの二万余騎も続いて到着した〔注:鼠尼施は咄陸五啜の一つで、鷹娑川に居た。のちに鷹娑都督府を置いた〕。前軍総管の蘇定方が五百騎を率いて駆けつけてこれを撃つと、西突厥は大敗した。二十里追撃し、千五百余人を殺し捕らえ、得た馬や武具は山野に連なって数えきれないほどであった。副大総管の王文度はその功を妬み、知節に言った——「今度は賊を破ったとはいえ、官軍にも死傷が出ました。危険に乗じて軽はずみに突出するのは、成敗を分けるやり方というものです。何をそう急ぐことがありましょう。今後は常に方陣を組み、輜重を内に置いて、賊に遭えば戦う。これが万全の策です」。さらに、別に勅を得たと偽って、知節は勇を恃んで敵を軽んじるので文度に節制を委ねる、と称し、軍を収めて深入りを許さなかった。士卒は終日馬に跨がり、甲を着けて陣を組み、疲れきってしまい、馬も多くが痩せて死んだ。定方が知節に言った——「軍を出したのは賊を討つためです。それがいまは自守するばかりで、坐したまま自ら疲れ弊れているのですから、賊に遭えば必ず負けます。こんな臆病では、どうして功を立てられましょう。それに主上は公を大将となさったのです、どうしてさらに軍の副将に号令を専らにさせられましょう。そんなはずはありません。文度を捕らえ、急ぎ上表して主上にお知らせください」。知節は従わなかった。

恒篤城に至ると〔注:『新書』は「怛篤城」に作る〕、胡人の一群が帰順してきた。文度は「こやつらは我らが軍を返すのを待って、また賊に戻るのだ。皆殺しにしてその財産を取るにこしたことはない」と言った。定方は「そんなことをすれば自分から賊になるだけです。どうして叛く者を伐つと言えましょう」と言った。文度はとうとう彼らを殺し、その財を分けたが、定方ひとりは受け取らなかった。軍が引き揚げると、文度は詔を偽った罪で死に当たったが、特に名籍を除かれるだけで済み、知節も逗留して賊を追いつけなかった罪に問われ、死を減じられて免官となった。

⑯この年、太常卿・駙馬都尉の高履行を益州長史とした〔注:高履行は太宗の娘の東陽公主を娶っていた〕。

⑰韓瑗が上疏して、褚遂良のために冤罪を訴えて言った——「遂良は国を思って家を忘れ、身を投げ出して事にあたり、その操は風霜のごとく、その心は鉄石のごとくで、社稷の旧臣、陛下の賢い補佐役です。罪状も聞こえないのに朝廷から斥け去られ、内外の民はみなその処置を嘆いております〔注:『論語』に、孔子が「まっすぐな者を挙げて曲がった者の上に置けば民は服し、曲がった者を挙げてまっすぐな者の上に置けば民は服さない」と言っている〕。臣が聞きますに、晋の武帝は寛やかで、劉毅を誅することはありませんでした〔注:このことは八十一巻、太康三年に見える〕。漢の高祖は仁が深く、周昌の直言に怒りませんでした〔注:注はすでに前に見える〕。ところが遂良が遷されてから、もう寒暑が一巡りしました。陛下に逆らった罰は、これで足りております。伏して願わくは、遠く罪なきさまをお察しくださり、罪ならぬ罪をいくらか寛くし〔注:緬とは遠いという意である〕、ささやかな真心をお憐れみになって、人情に順ってくださいますよう」。高宗は瑗に言った——「遂良の心情は、朕も知っている。だが彼は道理に背いて上を犯すのを好むから、これでもって責めたのだ。卿はどうしてそこまで言うのか」。瑗は答えた——「遂良は社稷の忠臣で、讒言とへつらいによって毀たれたのです。むかし微子が去って殷の国は亡び〔注:殷の紂の暴虐が日ごとにひどくなると、微子は楽器を抱いて周へ奔った。武王はそこで諸侯に告げて「殷には重い罪がある、伐たないわけにはいかない」と言い、ついに紂を伐って滅ぼした〕、張華がいたおかげで綱紀は乱れませんでした〔注:このことは八十二巻から八十三巻に見える〕。陛下が理由もなく旧臣を棄て逐うのは、国家の福ではないと恐れます」。高宗は聞き入れなかった。瑗は言葉が用いられないので、田里に帰らせてほしいと願い出たが、高宗は許さなかった。

⑱劉洎の子が父の冤罪を訴え、貞観の末に褚遂良に讒言されて死んだのだと称した〔注:このことは百九十八巻、貞観十九年に見える〕。李義府もこれを助けた。高宗が近臣に問うと、みな義府の意向に迎合して、口をそろえて冤罪だと言った。ただ給事中で長安の人である楽彦瑋だけがこう言った——「劉洎は大臣です。人主にしばらくご不例があったからといって、どうしてすぐさま自分を伊尹・霍光になぞらえてよいでしょう。いま洎の罪を雪ぐというのは、先帝の刑の用い方が不当だったと言うことになりましょうか」。高宗はその言葉をもっともとして、この件を沙汰止みにした。

==顯慶元年==
春，正月，辛未，以皇太子忠爲梁王、梁州刺史；立皇后子代王弘爲皇太子，生四年矣。忠旣廢，官屬皆懼罪亡匿，無敢見者；右庶子李安仁獨候忠，泣涕拜辭而去。安仁，綱之孫也。
壬申，赦天下，改元。
二月，辛亥，贈武士彠司徒，賜爵周國公。
三月，以度支侍郎杜正倫爲黃門侍郎、同三品。
夏，四月，壬子，矩州人謝無靈舉兵反，黔州都督李子和討平之。
己未，上謂侍臣曰︰「朕思養人之道，未得其要，公等爲朕陳之！」來濟對曰︰「昔齊桓公出游，見老而飢寒者，命賜之食，老人曰︰『願賜一國之飢者。』賜之衣，曰︰『願賜一國之寒者。』公曰︰『寡人之廩府安足以周一國之飢寒！』老人曰︰『君不奪農時，則國人皆有餘食矣！不奪蠶要，則國人皆有餘衣矣！』故人君之養人，在省其征役而已。今山東役丁，歲別數萬，役人則人大勞，取庸則人大費。臣願陛下量公家所須外，餘悉免之。」上從之。
六月，辛亥，禮官奏停太祖、世祖配祀，以高祖配昊天於圜丘，太宗配五帝於明堂；從之。
秋，七月，乙丑，西洱蠻酋長楊棟附、顯和蠻酋長王郎祁、郎‧昆‧棃‧盤四州酋長王伽衝等帥衆內附。
癸未，以中書令崔敦禮爲太子少師、同中書門下三品。
八月，丙申，固安昭公崔敦禮薨。
辛丑，葱山道行軍總管程知節擊西突厥，與歌邏、處月二部戰於榆慕谷，大破之，斬首千餘級，副總管周智度攻突騎施、處木昆等部於咽城，拔之，斬首三萬級。
乙巳，龜茲王布失畢入朝。
李義府恃寵用事。洛州婦人淳于氏，美色，繫大理獄，義府屬大理寺丞畢正義枉法出之，將納爲妾，大理卿段寶玄疑而奏之。上命給事中劉仁軌等鞫之，義府恐事洩，逼正義自縊於獄中。上知之，原義府罪不問。
侍御史漣水王義方欲奏彈之，先白其母曰︰「義方爲御史，視姦臣不糾則不忠，糾之則身危而憂及於親爲不孝，二者不能自決，柰何？」母曰︰「昔王陵之母，殺身以成子之名。汝能盡忠以事君，吾死不恨！」義方乃奏︰「義府於輦轂之下，擅殺六品寺丞；就云正義自殺，亦由畏義府威，殺身以滅口。如此，則生殺之威，不由上出，漸不可長，請更加勘當！」於是對仗，叱義府令下；義府顧望不退。義方三叱，上旣無言，義府始趨出，義方乃讀彈文。上釋義府不問，而謂義方毀辱大臣，言辭不遜，貶萊州司戶。
九月，括州暴風，海溢，溺四千餘家。
冬，十一月，丙寅，生羌酋長浪我利波等帥衆內附，以其地置柘、栱二州。
十二月，程知節引軍至鷹娑川，還西突厥二萬騎，別部鼠尼施等二萬餘騎繼至，前軍總管蘇定方帥五百騎馳往擊之，西突厥大敗，追奔二十里，殺獲千五百餘人，獲馬及器械，綿亙山野，不可勝計。副大總管王文度害其功，言於知節曰︰「今茲雖云破賊，官軍亦有死傷，乘危輕脫，乃成敗之法耳，何急而爲此！自今常結方陳，置輜重在內，遇賊則戰，此萬全策也。」又矯稱別得旨，以知節恃勇輕敵，委文度爲之節制，遂收軍不許深入。士卒終日跨馬，被甲結陳，不勝疲頓，馬多瘦死。定方言於知節曰︰「出師欲以討賊，今乃自守，坐自困敝，若遇賊必敗；懦怯如此，何以立功！且主上以公爲大將，豈可更遣軍副專其號令，事必不然。請囚文度，飛表以聞。」知節不從。
至恆篤城，有羣胡歸附，文度曰︰「此屬伺我旋師，還復爲賊，不如盡殺之，取其資財。」定方曰︰「如此乃自爲賊耳，何名伐叛！」文度竟殺之，分其財，獨定方不受。師旋，文度坐矯詔當死，特除名；知節亦坐逗遛追賊不及，減死免官。
是歲，以太常卿駙馬都尉高履行爲益州長史。
韓瑗上疏，爲褚遂良訟冤曰︰「遂良體國忘家，捐身徇物，風霜其操，鐵石其心，社稷之舊臣，陛下之賢佐。無聞罪狀，斥去朝廷，內外甿黎，咸嗟舉措。臣聞晉武弘裕，不貽劉毅之誅；漢祖深仁，無恚周昌之直。而遂良被遷，已經寒暑，違忤陛下，其罰塞焉。伏願緬鑒無辜，稍寬非罪，俯矜微款，以順人情。」上謂瑗曰︰「遂良之情，朕亦知之。然其悖戾好犯上，故以此責之，卿何言之深也！」對曰︰「遂良社稷忠臣，爲讒諛所毀。昔微子去而殷國以亡，張華存而綱紀不亂。陛下無故棄逐舊臣，恐非國家之福！」上不納。瑗以言不用，乞歸田里；上不許。
劉洎之子訟其父冤，稱貞觀之末，爲褚遂良所譖而死，李義府復助之。上以問近臣，衆希義府之旨，皆言其枉。給事中長安樂彥瑋獨曰︰「劉洎大臣，人主暫有不豫，豈得遽自比伊、霍！今雪洎之罪，謂先帝用刑不當乎？」上然其言，遂寢其事。
