# 卷233 唐紀四十九 — 德宗神武聖文皇帝八六年

①春、詔して岐山の無憂王寺の仏の指骨を取り出させ、宮中に迎え置き、さらに諸寺へ回して人々に拝ませた。都じゅうが傾くほど押しかけて礼拝し、施される財は巨万にのぼった。二月、乙亥、中使を遣わしてもとの場所に葬り返させた。

②はじめ、朱滔が貝州で敗れたとき〔注:二百三十一巻・興元元年に見える〕、その棣州刺史の趙鎬は州ごと王武俊に降ったが、やがて武俊のとがめを受け、召し出されても行かなかった。田緒は残忍な男で、その兄の田朝は李納に仕えて斉州刺史となっていた。ある者が「納は朝を魏へ迎え入れようとしている」と言ったので、緒は恐れた。判官の孫光佐らが緒のために策を立て、納に厚く賄賂を贈り、そのうえで納に「趙鎬を招き寄せて棣州を取れ」と説いて機嫌をとり、そのついでに田朝を京師へ送ってくれるよう頼んだ。納はこれに従った。丁酉、趙鎬は棣州ごと納に降った。三月、武俊は子の王士真を遣わしてこれを撃たせたが、勝てなかった。

③回鶻の忠貞可汗の弟が忠貞を弑して自ら位に即いた〔注:『考異』にいう。『新伝』には「可汗は少可敦の葉公主に毒殺され、可汗の弟がそこで自ら立った」とある。今は『実録』に従う〕。その大相の頡干迦斯は西へ吐蕃を撃ちに出たまま帰っていなかった。夏、四月、次相が国人を率いて簒奪者を殺し、忠貞の子の阿啜を立てて可汗とした。年は十五であった。

④五月、王武俊が冀州に屯して趙鎬を撃とうとすると、鎬は配下を率いて鄆州へ逃げ、李納は兵を分けてそこを押さえた。田緒は孫光佐を鄆州へ遣わし、詔をいつわって棣州を納に属させた。武俊は怒り、子の王士清を遣わして貝州を伐たせ、経城など四県を取った。

⑤回鶻の頡干迦斯は吐蕃と戦って利あらず、吐蕃は激しく北庭を攻めた。北庭の人々は回鶻の際限ない取り立てに苦しんでいたので、沙陀の酋長の朱邪尽忠ともども吐蕃に降った〔注:のちに沙陀が来降することの伏線である〕。節度使の楊襲古は麾下二千人を率いて西州へ逃れた。六月、頡干迦斯が兵を率いて国へ帰ると、次相は彼が可汗の廃立を行うのではないかと恐れ、可汗ともども郊外まで出迎え、ひれ伏して勝手に擁立した経緯を自ら申し述べ、「今日は、ただ大相のお心ひとつで生きも死にもいたします」と言った。そして郭鋒がもたらした国信の品々をずらりと並べ、ことごとくこれに贈った〔注:去年、唐は郭鋒を遣わして忠貞可汗を册命した〕。可汗は拝して泣きながら言った——「わたくしは愚かで幼うございます。もし幸いに位に即けましたなら、ひたすらアタに養っていただくばかりで、国政には口を出しません」。虜は父をアタと呼ぶ〔注:『唐韻』に、北の人は父を阿爹と呼ぶ、とある〕。頡干迦斯はそのへりくだりに心を動かされ、可汗を抱きかかえて哭き、そのまま臣下の礼をとった。贈られた品はすべて随行の者たちに分け与え、自分は何も受け取らなかった。国中はこれによっていくらか落ち着いた。

秋、頡干迦斯は国じゅうの兵数万をあげて北庭を回復しようとしたが、またも吐蕃に敗れ、死者は大半にのぼった。楊襲古は残った数百の兵をまとめて西州へ帰ろうとしたが、頡干迦斯は「まずはわたしと一緒に牙帳まで来られよ」とだましてこれを引き留め、そのまま帰さず、ついに殺してしまった。安西はこれによって連絡が絶え、存亡もわからなくなった〔注:北庭がすでに吐蕃に陥ちて安西への路が絶えたので、その消息がわからなくなったのである〕。それでも西州はなお唐のために守り通していた。

葛祿は勝ちに乗じて回鶻の浮図川を取った〔注:浮図川は烏徳犍山の西北にある〕。回鶻は震え上がり、西北の部落をすべて牙帳の南へ移してこれを避けた。そして達北特勒の梅録を郭鋒に随行させてともに来させ、忠貞可汗の喪を告げ、あわせて册命を求めさせた。これより先、回鶻の使者が中国に入るときは、その態度が驕り高ぶっており、刺史もみな対等の礼で応じていた。梅録が豊州に至ると、刺史の李景略は気迫で押さえつけようとして、梅録に「可汗が亡くなられたと聞いた。弔いの礼を述べたい」と言った。景略は先に高い丘の上に構えて座り、梅録は背を丸め頭を垂れて前に進み出て哭した〔注:「俯」は頭を低くすること。「僂」は背を曲げることである〕。景略は彼を撫でて「可汗が世を去られたのだ、そなたの哀しみに力を添えよう」と言った。梅録の驕った顔つきも荒々しい気勢も、すっかり消え失せてしまった。これより回鶻の使者は来るたびに庭で景略を拝するようになり、その威名は塞外にまで聞こえた。

冬、十月、辛亥、郭鋒がようやく回鶻から帰った。

⑥十一月、庚午、上は圜丘で祀りを行った。

⑦上はたびたび李納に詔して棣州を王武俊に返させようとしたが、納はあらゆる手で引き延ばし、海州と交換してほしいと朝廷に願い出た。上は許さなかった。そこで納は、まず武俊に田緒の四県を返させるよう詔してほしいと請い、上はこれに従った。十二月、納はようやく棣州を武俊に返した。

六年
春，詔出岐山無憂王寺佛指骨迎置禁中，又送諸寺以示衆，傾都瞻禮，施財巨萬；二月，乙亥，遣中使復葬故處。
初，朱滔敗於貝州，其棣州刺史趙鎬以州降於王武俊，旣而得罪於武俊，召之不至。田緒殘忍，其兄朝，仕李納爲齊州刺史。或言納欲納朝於魏，緒懼；判官孫光佐等爲緒謀，厚賂納，且說納招趙鎬取棣州以悅之，因請送朝於京師；納從之。丁酉，鎬以棣州降于納。三月，武俊使其子士眞擊之，不克。
回鶻忠貞可汗之弟弒忠貞而自立，其大相頡干迦斯西擊吐蕃未還，夏，四月，次相帥國人殺篡者而立忠貞之子阿啜爲可汗，年十五。
五月，王武俊屯冀州，將擊趙鎬，鎬帥其屬奔鄆州；李納分兵據之。田緒使孫光佐如鄆州，矯詔以棣州隸納；武俊怒，遣其子士清伐貝州，取經城等四縣。
回鶻頡干迦斯與吐蕃戰不利，吐蕃急攻北庭。北庭人苦於回鶻誅求，與沙陀酋長朱邪盡忠皆降於吐蕃；節度使楊襲古帥麾下二千人奔西州。六月，頡干迦斯引兵還國，次相恐其有廢立，與可汗皆出郊迎，俯伏自陳擅立之狀，曰︰「今日惟大相死生之。」盛陳郭鋒所齎國信，悉以遺之。可汗拜且泣曰︰「兒愚幼，若幸而得立，惟仰食於阿多，國政不敢豫也。」虜謂父爲阿多，頡干迦斯感其卑屈，持之而哭，遂執臣禮，悉以所遺頒從行者，己無所受。國中由是稍安。
秋，頡干迦斯悉舉國兵數萬將復北庭，又爲吐蕃所敗，死者大半。襲古收餘衆數百，將還西州，頡干迦斯紿之曰︰「且與我同至牙帳；」旣而留不遣，竟殺之。安西由是遂絕，莫知存亡，而西州猶爲唐固守。
葛祿乘勝取回鶻之浮圖川，回鶻震恐，悉遷西北部落於牙帳之南以避之；遣達北特勒梅錄隨郭鋒偕來，告忠貞可汗之喪，且求册命。先是，回鶻使者入中國，禮容驕慢，刺史皆與之鈞禮。梅錄至豐州，刺史李景略欲以氣加之，謂梅錄曰︰「聞可汗新沒，欲申弔禮。」景略先據高壟而坐，梅錄俯僂前哭。景略撫之曰︰「可汗棄代，助爾哀慕。」梅錄驕容猛氣，索然俱盡。自是回鶻使至，皆拜景略於庭，威名聞塞外。
冬，十月，辛亥，郭鋒始自回鶻還。
十一月，庚午，上祀圜丘。
上屢詔李納以棣州歸王武俊，納百方遷延，請以海州易之於朝廷；上不許。乃請詔武俊先歸田緒四縣；上從之。十二月，納始以棣州歸武俊。
