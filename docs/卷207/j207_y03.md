# 卷207 唐紀二十三 — 則天順聖皇后下二年

> 巻 207 / 294 ・ 唐紀二十三 ・ 年号: 則天順聖皇后下二年 ・ 西暦: 702 CE

==二年〔注:壬寅、702年〕==

①春、正月、乙酉、はじめて武挙(武科の登用試験)を設けた〔注:武挙の制には、長垜・馬射・歩射・平射・筒射・馬槍・翹関・負重・身材の選がある。『唐六典』にいう——武挙は七等でその人を試す。一に長垜を射ること。長垜を射て三十発が第三院を出なければ及第とし、中院に入れば上、次院に入れば次上、外院に入れば次とする。二に騎射。放って皆当たれば上、当たったり外れたりすれば次上、まったく当たらなければ次。三に馬槍。三板・四板を上、二板を次上、一板および当たらないものを次。四に歩射。草人を射当てた者を上とし、当たっても法に適わないもの、法に適っても当たらないものを次とする。五に材貌。身長六尺以上を次上、それ以下を次とする。六に言語。神采があって統領に堪える者を次上、無い者を次とする。七に挙重。翹関のことで、おおむね五度上げたものを及第とする。いずれも成績の高い者を試して名を奏聞する〕。

②突厥が塩・夏の二州を侵した。三月、庚寅、突厥が石嶺を破り〔注:忻州定襄県に石嶺関がある。杜佑は、定襄はもと漢の陽曲県で、石嶺関ははなはだ険固だという。漢の定襄郡は今の馬邑郡の地にあたる〕、并州を侵した。雍州長史の薛季昶を右台大夫の代行とし、山東防禦軍大使に充て、滄・瀛・幽・易・恒・定などの諸州の軍はみな季昶の指揮を受けさせた。夏、四月、幽州刺史の張仁愿に幽・平・嬀・檀の防禦を専管させ、なお季昶と連絡を取り合って突厥を防がせた。

③五月、壬申、蘇安恒がふたたび上疏して言った——「臣が聞きますに、天下とは神堯(高祖)・文武(太宗)の天下です〔注:高祖は神堯皇帝、太宗は文武皇帝〕。陛下は正統の位におられるとはいえ、実は唐氏の旧い基業に因ったものです。いま太子は呼び戻され〔注:廬陵王を房陵から呼び戻し、ふたたび太子としたことをいう〕、年齢も徳もともに盛んです。陛下は宝位を貪って母子の深い恩を忘れておいでです。それでどのような御顔で唐家の宗廟にまみえ、どのような誥命をもって大帝(高宗)の墳陵に詣でられましょうか〔注:高宗は天皇大帝と称する〕。陛下はなにゆえ日夜憂いを積まれ、鐘が鳴り漏刻の尽きようとしていることをお悟りにならないのですか〔注:魏の田豫が老いを告げて言った、「たとえば鐘が鳴り漏が尽きたのに夜歩きをやめないようなもの、これは罪人である」と〕。臣の愚考では、天意も人事も、いずれ李家に還るのです。陛下は天位に安んじておられますが、物は極まれば反り、器は満ちれば傾くことを、まるでご存じない。臣がどうして一朝の命を惜しんで、万乗の国を安んじないでいられましょうか」〔注:死を顧みずに上疏し、それによって国を安んじようとしたことをいう〕。太后はこれもまた罪としなかった。

④乙未、相王を并州牧とし、安北道行軍元帥に充て、魏元忠をその副とした。

⑤六月、壬戌、神都留守の韋巨源を京師に召し、副留守の李嶠をこれに代えた。

⑥秋、七月、甲午、突厥が代州を侵した。

⑦司僕卿の張昌宗〔注:光宅元年、太僕寺を司僕寺と改めた〕の兄弟は貴く盛んで、その勢いは朝野を圧した。八月、戊午、太子・相王・太平公主が上表して昌宗を王に封じるよう請うたが、制して許されなかった。壬戌、また請うたので、鄴国公の爵を賜った。

⑧勅——「今より後、揚州および豫州・博州の余党を告発する者があっても〔注:揚州の事は二百三巻光宅元年に、豫州・博州の事は二百四巻垂拱四年に見える〕、一切問わない。内外の官司は取り扱ってはならない」。

⑨九月、乙丑朔、日食があった。欠けきらずに鉤のようであったが、神都ではその皆既が見えた。

⑩壬申、突厥が忻州を侵した。

⑪己卯、吐蕃がその臣の論弥薩を遣わして和を求めてきた。

⑫庚辰、太子賓客の武三思を大谷道大総管とし、洛州長史の敬暉をその副とした。辛巳、また相王旦を并州道元帥とし、三思と武攸宜・魏元忠をその副とし、姚元崇を長史、司礼少卿の鄭杲を司馬とした〔注:突厥を撃とうとしたのである〕。しかし結局出動しなかった。

⑬癸未、論弥薩を麟徳殿で饗応した〔注:麟徳殿は大明宮の右銀台門の内にある。殿の西の重廊の後ろが、すなわち翰林院である。この殿には三面あるので、三殿ともいう〕。当時、涼州都督の唐休璟が入朝しており、この宴に列していた。弥薩はしきりに彼をうかがい見た。太后がその理由を尋ねると、答えて言った——「洪源の戦いで、この将軍は猛烈で敵うものがありませんでした。それで顔を知っておきたかったのです」。太后は休璟を右武威・金吾の二衛大将軍に抜擢した〔注:龍朔年間に左・右威衛を左・右武威衛と改めた〕。休璟は辺境の事に習熟しており、碣石より西、四鎮を越えて万里に連なる山川の要害を、すべて記憶していた〔注:碣石は遼西にあり、四鎮は西域にある。これは唐の西・北二辺の山川要害を、休璟がみな記憶できたことをいう〕。

⑭冬、十月、甲辰、天官侍郎・同平章事の顧琮が薨じた。

⑮戊申、吐蕃の贊普が一万余人を率いて茂州を侵した。都督の陳大慈はこれと四たび戦い、いずれも破って、千余級を斬った。

⑯十一月、辛未、監察御史の魏靖が上疏して言った——「陛下はすでに来俊臣の姦悪を知られ、極刑に処されました。願わくは俊臣らが取り調べた大獄を詳しく再審し、その冤罪を晴らしてください」。太后はそこで監察御史の蘇頲に命じて俊臣らの旧獄を調べ直させた。これによって冤を雪いで免れた者がはなはだ多かった〔注:『考異』にいう——『松窗雑録』に「中宗がかつて宰相の蘇瓌・李嶠の子を召して謁見させた。二人の丞相の子はどちらも幼く、赭袍の前に迎えて撫で、賜与ははなはだ手厚かった。そこで二児に語って言った、『おまえたちが読み通した書のうち、私に奏することのできるものを言ってみよ』。頲が応えて言った、『木は縄に従えば正しくなり、君は諫めに従えば聖となる』。嶠の子は名を伝えないが、これも進み出て言った、『朝に川を渡る者の脛を斬り、賢人の心を割く』。上は言った、『蘇瓌には子があり、李嶠には子が無い』」とある。按ずるに、頲はこの年すでに御史となっており、瓌が宰相であった時、頲は中書舎人で、父子が同時に枢密を掌っていたのであって、幼年ではない。今は取らない〕。頲は蘇夔の曾孫である〔注:頲は他鼎の翻。蘇夔は威の子で、隋の開皇の初めに楽を議した〕。

⑰戊子、太后が南郊を祀り、天下に大赦した。

⑱十二月、甲午、魏元忠を安東道安撫大使とし、羽林衛大将軍の李多祚を検校幽州都督、右羽林衛将軍の薛訥・左武衛将軍の駱務整をその副とした。

⑲戊申、北庭都護府を庭州に置いた〔注:太宗が高昌を平定し、西州の北に庭州を置いた。すなわち漢の車師後王の地である〕。

⑳侍御史の張循憲が河東採訪使となったが、疑わしい案件があって決しかね、これを苦にして、侍吏に尋ねた——「このあたりに、ともに事を議するに足るよい客人はいないか」。吏は、前の平郷尉で猗氏の張嘉貞に異才があると言った〔注:魏収『志』に、広平郡任県に平郷城があるとある。隋は平郷県を置き、古の鉅鹿城に治して、邢州に属した。猗氏県は古の郇国で、漢以来河東郡に属した〕。循憲は召し寄せて会い、事を尋ねた。嘉貞は条ごとに分析し、理に沿って分けてみせ〔注:条に随ってこれを析き、理に随ってこれを分ける〕、どれもはっと目の覚めるようであった〔注:洗は洒と同じ。洗然とは、悚然(はっとするさま)である〕。循憲はそこで奏文を作ってくれるよう頼んだが、いずれも自分の思い及ばぬところだった。循憲は帰って太后に謁見した。太后はその奏をよしとした。循憲は嘉貞のしたことを詳しく述べ、そのうえで自分の官を彼に授けてほしいと請うた。太后は言った——「朕には、自ら賢者を登用するための官のひとつも無いとでも言うのか」。そこで嘉貞を召し、内殿に入れて謁見させ、語り合って大いに悦び、ただちに監察御史に任じた。また循憲を司勲郎中に抜擢した〔注:唐の司勲郎は邦国の官人の勲級を掌り、吏部に属する〕。その人を得たことを賞したのである。

==二年==
春，正月，乙酉，初設武舉。
突厥寇鹽、夏二州。三月，庚寅，突厥破石嶺，寇幷州。以雍州長史薛季昶攝右臺大夫，充山東防禦軍大使，滄，瀛、幽、易、恆、定等州諸軍皆受季昶節度。夏，四月，以幽州刺史張仁愿專知幽、平、嬀、檀防禦，仍與季昶相知，以拒突厥。
五月，壬申，蘇安恆復上疏曰︰「臣聞天下者，神堯、文武之天下也，陛下雖居正統，實因唐氏舊基。當今太子追迴，年德俱盛，陛下貪其寶位而忘母子深恩，將何聖顏以見唐家宗廟，將何誥命以謁大帝墳陵？陛下何故日夜積憂，不知鍾鳴漏盡！臣愚以爲天意人事，還歸李家。陛下雖安天位，殊不知物極則反，器滿則傾。臣何惜一朝之命而不安萬乘之國哉！」太后亦不之罪。
乙未，以相王爲幷州牧，充安北道行軍元帥，以魏元忠爲之副。
六月，壬戌，召神都留守韋巨源詣京師，以副留守李嶠代之。
秋，七月，甲午，突厥寇代州。
司僕卿張昌宗兄弟貴盛，勢傾朝野。八月，戊午，太子、相王、太平公主上表請封昌宗爲王，制不許；壬戌，又請，乃賜爵鄴國公。
敕：「自今有告言揚州及豫、博餘黨，一無所問，內外官司無得爲理。」
九月，乙丑朔，日有食之，不盡如鉤，神都見其旣。
壬申，突厥寇忻州。
己卯，吐蕃遣其臣論彌薩來求和。
庚辰，以太子賓客武三思爲大谷道大總管，洛州長史敬暉爲副；辛巳，又以相王旦爲幷州道元帥，三思與武攸宜、魏元忠爲之副；姚元崇爲長史，司禮少卿鄭杲爲司馬；然竟不行。
癸未，宴論彌薩於麟德殿。時涼州都督唐休璟入朝，亦預宴。彌薩屢窺之。太后問其故，對曰：「洪源之戰，此將軍猛厲無敵，故欲識之。」太后擢休璟爲右武威、金吾二衞大將軍。休璟練習邊事，自碣石以西踰四鎭，緜亙萬里，山川要害，皆能記之。
冬，十月，甲辰，天官侍郎、同平章事顧琮薨。
戊申，吐蕃贊普將萬餘人寇茂州，都督陳大慈與之四戰，皆破之，斬首千餘級。
十一月，辛未，監察御史魏靖上疏，以爲：「陛下旣知來俊臣之姦，處以極法，乞詳覆俊臣等所推大獄，伸其枉濫。」太后乃命監察御史蘇頲按覆俊臣等舊獄，由是雪免者甚衆。頲，夔之曾孫也。
戊子，太后祀南郊，赦天下。
十二月，甲午，以魏元忠爲安東道安撫大使，羽林衞大將軍李多祚檢校幽州都督，右羽林衞將軍薛訥、左武衞將軍駱務整爲之副。
戊申，置北庭都護府於庭州。
侍御史張循憲爲河東采訪使，有疑事不能決，病之，問侍吏曰：「此有佳客，可與議事者乎？」吏言前平鄕尉猗氏張嘉貞有異才，循憲召見，詢以事；嘉貞爲條析理分，莫不洗然；循憲因請爲奏，皆意所未及。循憲還，見太后，太后善其奏，循憲具言嘉貞所爲，且請以己之官授之。太后曰：「朕寧無一官自進賢邪！」因召嘉貞，入見內殿，與語，大悅，卽拜監察御史；擢循憲司勳郎中，賞其得人也。
