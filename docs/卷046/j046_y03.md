# 卷046 漢紀三十八 — 肅宗孝章皇帝上三年

> 巻 46 / 294 ・ 漢紀三十八 ・ 年号: 肅宗孝章皇帝上三年 ・ 西暦: 78 CE

[← 巻インデックス](README.md)

三年〔注:戊寅(つちのえとら)の年、紀元七八年〕。

春、正月、己酉の日。明堂(めいどう)で先祖を祀(まつ)り、霊台(れいだい)に登り、天下に大赦(たいしゃ)を行った。

馬防が布橋を攻め、大いに破った。布橋は部族の者一万人余りを率いて降伏し、詔(みことのり)を下して馬防を呼び戻した〔注:『考異』に「『帝紀』では羌を破ったのを四月とする。おそらく春に破り、京師では四月になってはじめて(その報せが)聞こえたのだろう。今は『馬防伝』に従う」とある〕。耿恭(こうきょう)を残してまだ服従していない者たちを撃たせ、千人余りの首を斬り捕らえた。すると勒姐(ろくしゃ)・燒何(しょうか)など十三の部族、数万人がみな耿恭のもとへ来て降伏した。

![耿恭(こうきょう)、勒姐(ろくしゃ)・燒何(しょうか)ら十三部族の降伏を受ける——建初三年(七八年)春、馬防が布橋を大いに破り、布橋は部族一万余人を率いて降伏したので詔で馬防は呼び戻された(胡注: 『考異』は帝紀の「四月」を京師に報せが届いた月と見て馬防伝に従う)。残った耿恭がまだ服従しない者たちを撃って千余の首級・捕虜を得ると、勒姐・燒何など十三の部族、数万人がみな耿恭のもとへ来て降った。しかし耿恭はかつて竇固を涼州方面の鎮撫に当てるよう上奏して馬防の意に逆らっていたため(胡注: 隴西出征のときの上奏)、陣営を監督する謁者が意向を汲んで「軍務に身を入れていない」と上奏し、耿恭は召し返されて獄に下され免官となった。黄土の丘に囲まれた高原の谷を鳥瞰し、中央に無地の旗を掲げた少数の槍兵に護られて馬上に座る甲冑の耿恭、四方の山肌から羊の群れと馬を連れて曲線を描いて降りてくる氈衣・毛皮帽の羌人の長い列、先頭で弓と槍を地に置いて跪く者たち、斜面に散る氈幕、霧の遠山、丘の黄土のみ淡い黄土色。](../images/卷046/j046_y03_rokusha.jpg)耿恭はかつて意見を上奏して馬防の機嫌を損ねたことがあった〔注:はじめ耿恭は隴西(ろうせい)へ出るにあたり、竇固(とうこ)を涼州方面の鎮撫(ちんぶ)に当てるよう上奏で薦めた。これによって大いに馬防の意に逆らった〕。そこで陣営を監督する謁者(えっしゃ)が(馬防の)意向を汲(く)んで、耿恭は軍務に身を入れていないと上奏した。耿恭はこれに連座して召し返され、獄に下されて免官となった。

三月、癸巳の日。貴人の竇氏(とうし)を立てて皇后とした。

そもそも顕宗(明帝)の代に、虖沱(こだ)・石臼(せききゅう)の河を整備し、都慮(とりょ)から羊腸倉(ようちょうそう)まで〔注:石臼河は今の定州唐県の東北にある。羊腸倉は晋陽(しんよう)の西北にあり、石の坂道がうねうねと羊の腸のようだったので、こう名づけられた〕、水路で物資を運べるようにしようとした。太原(たいげん)の役人や民は労役に苦しみ、何年たっても完成せず、死者は数えきれないほどだった。帝は郎中(ろうちゅう)の鄧訓(とうくん)を謁者として、この事業を監督させた。鄧訓はよく調べ量って〔注:「隠括(いんかつ)」はよく調べ量ること。荀子に「曲がった木は必ず矯(た)めの道具で蒸し撓(たわ)めて、はじめてまっすぐになる」とある〕、完成は難しいと見抜き、詳しく上奏した。夏、四月、己巳の日。詔を下してその労役をやめさせ、かわりに驢馬(ろば)の車を用いることにし〔注:「輦(れん)」は車のこと〕、年に億万もの費用を節約し、労役の人夫数千人の命を救い生かした。

![鄧訓(とうくん)、羊腸倉(ようちょうそう)への水路工事を見きわめ労役を止める——明帝の代に虖沱・石臼の河を整備して都慮から羊腸倉まで(胡注: 石臼河は定州唐県の東北、羊腸倉は晋陽の西北にあり、石の坂道が羊の腸のようにうねるのでこの名がある)水運を通そうとしたが、太原の吏民は労役に苦しみ、何年たっても完成せず死者は数えきれなかった。章帝は郎中の鄧訓を謁者としてこの事業を監督させ、鄧訓はよく調べ量って(胡注: 「隠括」はよく調べ量ること、荀子の矯め木の喩え)完成は難しいと見抜き詳しく上奏した。夏四月己巳、詔でその労役をやめて驢馬の車(胡注: 「輦」は車)に切り替え、年に億万の費用を節約し、数千人の人夫の命を救った。鄧訓は鄧禹の子である。切り立った峡谷を鳥瞰し、下を蛇行する川と崖を羊の腸のようにうねって登る石の坂道、川岸の造りかけの堤と水路、放り出された木の櫓・籠・槌・天秤棒、岩に座り横たわる疲れきった人夫たち、上の岩棚で片手を挙げて工事を見渡す文官の冠と衣の若い鄧訓、坂道を袋を積んで登る驢馬の小さな荷車の列、谷を満たす霧と崖の松、川の水のみ淡い青。](../images/卷046/j046_y03_yocho.jpg)鄧訓は鄧禹(とうう)の子である。

閏月(うるうづき)、西域の假司馬(かしば)である班超(はんちょう)が、疏勒(そろく)・康居(こうきょ)・于窴(うてん)・拘彌(こうび)の兵一万人を率いて姑墨(こぼく)の石城を攻め、これを破って〔注:前漢書では、姑墨国は南城に治所を置き、長安から八千百五十里の距離にある〕、七百の首を斬った。

![班超(はんちょう)、西域諸国の兵を率いて姑墨(こぼく)の石城を攻める——建初三年閏月、西域の假司馬の班超が疏勒・康居・于窴・拘彌の兵一万人を率いて姑墨の石城(胡注: 前漢書では姑墨国は南城に治所を置き長安から八千百五十里)を攻めて破り、七百の首を斬った。砂漠の岩の高台に立つ小さな石壁のオアシス城を鳥瞰し、砂塵を上げて城壁へなだれ込む毛帽・カフタン姿の西域連合の騎兵、石壁に掛けられた梯子と胸壁で両手を挙げる守兵、手前右の岩の上で棹立ちの馬にまたがり剣で前方を指す甲冑の班超と無地の旗を持つ少数の漢兵、オアシスのポプラと小川、砂丘と霧に浮かぶ雪の遠山、砂塵のみ淡い黄土色。](../images/卷046/j046_y03_komoku.jpg)

冬、十二月、丁酉の日。馬防を車騎将軍(しゃきしょうぐん)とした。

武陵(ぶりょう)の漊中(るちゅう)の蛮族が反乱を起こした〔注:漊(る)は川の名で、源は今の澧州(れいしゅう)崇義県の西北の山に発する〕。

この年、役人が、広平王の羨(せん)・鉅鹿王の恭(きょう)・楽成王の党(とう)をそろって封国へ赴かせるよう上奏した。だが帝は情に篤(あつ)い性質で、諸王と離ればなれになるに忍びず、結局みな京師にとどめた。

三年
春，正月，己酉，宗祀明堂，登靈臺，赦天下。
馬防擊布橋，大破之，布橋將種人萬餘降，詔徵防還。留耿恭擊諸未服者，斬首虜千餘人，勒姐、燒何等十三種數萬人，皆詣恭降。恭嘗以言事忤馬防，監營謁者承旨，奏恭不憂軍事，坐徵下獄，免官。
三月，癸巳，立貴人竇氏爲皇后。
初，顯宗之世，治虖沱、石臼河，從都慮至羊腸倉，欲令通漕。太原吏民苦役，連年無成，死者不可勝算。帝以郎中鄧訓爲謁者，監領其事。訓考量隱括，知其難成，具以上言。夏，四月，己巳，詔罷其役，更用驢輦，歲省費億萬計，全活徒士數千人。訓，禹之子也。
閏月，西域假司馬班超率疏勒、康居、于窴、拘彌兵一萬人攻姑墨石城，破之，斬首七百級。
冬，十二月，丁酉，以馬防爲車騎將軍。
武陵漊中蠻反。
是歲，有司奏遣廣平王羨、鉅鹿王恭、樂成王黨俱就國；上性篤愛，不忍與諸王乖離，遂皆留京師。
