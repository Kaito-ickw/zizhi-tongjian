# 卷046 漢紀三十八 — 肅宗孝章皇帝上五年

> 巻 46 / 294 ・ 漢紀三十八 ・ 年号: 肅宗孝章皇帝上五年 ・ 西暦: 80 CE

[← 巻インデックス](README.md)

---

五年〔注:庚辰(かのえたつ)の年、紀元八〇年〕。

春、二月、庚辰(かのえたつ)朔(ついたち、月の第一日)、日食があった。詔(みことのり)を下して、忌憚(きたん)なく直言し、とことん諫(いさ)める人材を推挙させた。

荊(けい)・豫(よ)の諸郡の兵が漊中(ろうちゅう)の蛮族を討ち、これを破った。

夏、五月、辛亥(かのとい)の日、詔を下して言った。「朕(ちん)はまっすぐな士を待ち望み、席を斜めにして(=正座を崩して)、世に埋もれた異(い)なる意見を待っている〔注:「遅」は希望する・待ち望む意。「側席(そくせき)」は正座を崩して座ること、賢良の士を待つための姿勢である〕。先に到着した者たちは、それぞれすでに胸の憤(いきどお)りと不平を吐き出してくれた〔注:「懣(まん)」は不平・鬱憤(うっぷん)のこと〕。おおかた、そなたら大夫(たいふ)の志はわかった。みなを朕の身辺に置き、相談相手とし、その意見を取り入れたい。建武(けんぶ、光武帝)の詔書にもこうある。『堯(ぎょう)は臣下を職務によって試したのであって、言葉や文書だけで試したのではない』と。いま地方の官職に欠員が多いので、(そなたらを)みなそこに補い任じてよかろう」。

戊辰(つちのえたつ)の日、太傅(たいふ)の趙熹(ちょうき)が薨(こう)じた。

班超(はんちょう)は引き続き西域(さいいき)を平定したいと考え、上奏して兵を求めた。「私がひそかに思いますに、先帝(明帝)は西域を切り開こうとなさり、それゆえ北は匈奴(きょうど)を撃ち、西は外国へ使者を遣わされました。すると鄯善(ぜんぜん)・于窴(うてん、ホータン)はただちに(漢へ)心を寄せて従いました。いまや拘彌(こうび)・莎車(さしゃ、ヤルカンド)・疏勒(そろく、カシュガル)・月氏(げっし)・烏孫(うそん)・康居(こうきょ)が、あらためて帰服(きふく)したいと願っています。みなで力を合わせ、亀茲(きゅうじ、クチャ)を撃ち滅ぼし、漢への道を平らかに開きたいのです。もし亀茲を手に入れれば、西域でまだ服従していない国は、わずか百分の一にすぎなくなります。昔の論者はみな『三十六国を取ることは、匈奴の右腕を断つことだ』と言いました〔注:『漢書』に、漢が公主(こうしゅ、皇族の娘)を烏孫王の妻として送り、兄弟の交わりを結んだことこそ匈奴の右腕を断つことだ、とある。中国では南面(なんめん)するので、西が右にあたる〕。いま西域の諸国は、日の沈むかなたの果てに至るまで〔注:『西域伝』に、条支(じょうし)国から舟で西へ百日あまり行くと、日の沈むあたりに近い、とある〕、心を寄せ従わぬものはなく、大国も小国も喜びにあふれ、貢ぎ物を絶やしません。ただ焉耆(えんき)と亀茲だけが、なお服従しておりません〔注:本文の「延」は「焉」の誤り〕。私は以前、部下の官属(かんぞく)三十六人とともに遠い異郷へ使いし、ありとあらゆる困難と危険に遭いました。以来ひとり疏勒を守って、今で五年になります。胡夷(こい、西域の異民族)の実情やしきたりは、私もかなり心得ております。彼らの城郭(じょうかく)の国々は、大小を問わず、みな『漢に頼ることは天に頼るのと同じだ』と申します〔注:城郭の国々は、小さいものも大きいものも、その言うところはみな同じだということ〕。これによって確かめてみれば〔注:「効」は確かめる・効き目を見る意〕、葱嶺(そうれい、パミール高原)へ道を通すことができ、亀茲を討つことができます。いまこそ、亀茲の侍子(じし、人質として漢に来ている王子)である白霸(はくは)を、その国(亀茲)の王に立て、歩兵・騎兵数百をつけて送り込み、諸国と兵を連ねれば、年月(としつき)のうちには亀茲を捕らえることができましょう。夷狄(いてき)をもって夷狄を攻める、これこそ最善の計略です。私が見ますに、莎車・疏勒の田地は肥えて広く、牧草も豊かで、敦煌(とんこう)・鄯善のあたり(の痩せた土地)とは比べものになりません。兵を出しても中国(中原)の物資を費やすことなく、糧食はおのずと足りましょう。そのうえ姑墨(こぼ)・温宿(おんしゅく)の二王は、もともと亀茲が立てたものです〔注:温宿国は温宿城を都とし、長安から八千三百五十里の距離にある〕。彼らは亀茲と同じ種族ではなく、たがいに厭(いと)い苦しんでいます。その勢いからして、必ず投降してくる者が出るはずです。もしこの二国が降ってくれば、亀茲はおのずと崩れます。どうか私の上奏文を(担当の役所に)下げ渡し、実際の措置の参考にしてください。まことに万に一つの見込みでもあるならば、たとえ死んでも何の悔いがありましょうか。

![班超(はんちょう)、疏勒(そろく)から亀茲(きゅうじ)討伐の兵を請う上奏を書く——建初五年(八〇年)、班超は引き続き西域を平定したいと考えて上奏し、先帝が北は匈奴を撃ち西は使者を遣わして鄯善・于窴を帰服させたこと、いま拘彌・莎車・疏勒・月氏・烏孫・康居が帰服を願い、みなで亀茲を滅ぼして漢への道を開けば未服の国は百分の一に減ること、昔の論者が言う「三十六国を取れば匈奴の右腕を断つ」(胡注: 『漢書』は公主を烏孫王に嫁がせたことをいう、中国は南面するので西が右)、焉耆・亀茲だけが未服であること(胡注: 本文の「延」は「焉」の誤り)、部下三十六人と共に異郷へ渡り疏勒を守って五年になること、城郭諸国が「漢に頼るは天に頼るごとし」と言うこと、人質の王子白霸を亀茲王に立て数百の兵で送り込む「夷狄をもって夷狄を攻める」策、莎車・疏勒の肥沃な田地で糧食が足りること、亀茲が立てた姑墨・温宿の二王(胡注: 温宿城は長安から八千三百五十里)が必ず降ること、そして西域平定を見届けて陛下が万年の杯を挙げ祖廟に功を告げるのを見たいという願いを述べた。夕暮れの土壁のオアシス城を鳥瞰、屋上の露台で油灯のそばに膝をつき無地の竹簡に筆を執る高冠・素衣の班超、周囲に立つ少数の漢甲の部下と東の空を見やる一人、城外にポプラと小川と畑と休む駱駝、砂丘と雪嶺、夕空のみ淡い薔薇色。](../images/卷046/j046_y05_johyo.jpg)この私・班超は、取るに足らぬ身ながら、特に神霊のご加護をこうむってまいりました。願わくは、今すぐには倒れ伏して死ぬことなく、この目で西域が平定されるのを見届け、陛下が万年(ばんねん)を祝う杯を挙げ〔注:西域が平定されれば、廷臣がこぞって祝い、天子がそのために杯(さかずき)を挙げる、ということ〕、その功(いさお)を祖廟(そびょう、先祖を祀る廟)に告げ〔注:「薦」は奉る、「勳」は功(いさお)。班超は、西域平定の成功を祖廟に報告することを言っているのであろう〕、大きな喜びを天下にあまねく広められるよう願うばかりです」。

上奏文が奉られると、帝はその事業が成し遂げられると見抜き、兵を与えようと議した。平陵(へいりょう)の徐幹(じょかん)が上奏し、身を奮って班超を助けたいと願い出た。帝は徐幹を仮(かり)の司馬(しば)に任じ、刑を減じられた囚人〔注:「弛刑(しけい)」は刑徒(囚人)のこと。「義従(ぎじゅう)」は、みずから奮い立って従軍を願い出た者。あるいは、義従とは胡(こ)の協力兵をいうともいう〕や義勇の従軍者あわせて千人を率いて、班超のもとへ赴かせた。

![徐幹(じょかん)、刑徒と義勇兵千人を率いて西域の班超のもとへ向かう——上奏が奉られると帝はその事業が成し遂げられると見抜いて兵を与えようと議し、平陵の徐幹が身を奮って班超を助けたいと願い出た。帝は徐幹を仮の司馬に任じ、刑を減じられた囚人(胡注: 「弛刑」は刑徒のこと)と義勇の従軍者(胡注: 「義従」はみずから従軍を願い出た者、あるいは胡の協力兵ともいう)あわせて千人を率いて班超のもとへ赴かせた。荒涼とした山間の砂漠回廊を西へ蛇行する長い縦列を高い鳥瞰で、先頭で馬上から片腕を前へ挙げる漢甲・素兜の徐幹、その後ろに甲冑を着けず槍と荷を背負って歩く粗衣の男たち、無地の幟、物資を積む牛車、脇を進む毛帽の胡騎の一団、右下に今しがた通過した低い土塁の関門と崩れた烽火台、陽炎と砂丘と雪の遠山と空の鷲、砂のみ淡い黄土色。](../images/卷046/j046_y05_jokan.jpg)

これより先、莎車は漢の兵は出てこないだろうと思い込み、亀茲に降伏してしまっていた。また疏勒の都尉(とい)である番辰(はんしん)〔注:「番」は潘(はん)と読む〕もまた背いた。ちょうどそこへ徐幹が到着したので、班超は徐幹とともに番辰を攻め、これを大いに破って、千人余りの首を斬った。

![班超と徐幹、背いた疏勒の都尉・番辰(はんしん)を破る——これより先、莎車は漢の兵は出てこないと思い込んで亀茲に降伏し、疏勒の都尉である番辰(胡注: 「番」は潘と読む)もまた背いた。ちょうど徐幹が到着したので、班超は徐幹とともに番辰を攻め、これを大いに破って千人余りの首を斬った。班超はさらに亀茲を攻めたいと思ったが、烏孫の兵が強いのでその力を借りるのがよいと考え、烏孫は弓を引く兵十万を擁する大国で、武帝が公主を嫁がせ(胡注: 第二十一巻・元封六年)孝宣帝がついにその力を役立てた(胡注: 第二十四巻・本始三年)先例を引いて、使者を遣わして招き慰撫しともに力を合わせることを上奏し、帝はこれを受け入れた。ポプラ林と用水路の間の土壁のオアシス城を鳥瞰、砂塵を上げて破られた門へなだれ込む漢兵と粗衣の義勇兵と胡騎、用水路沿いや林へ散り逃げるカフタン・毛帽の番辰の手勢、左下の高みで無地の旗のもと馬上から攻撃を指揮する甲冑の班超と徐幹、落ちた盾、川、砂丘と雪嶺、砂塵のみ淡い黄土色。](../images/卷046/j046_y05_hanshin.jpg)班超は進んで亀茲を攻めたいと思ったが、烏孫の兵が強いので、その力を借りるのがよいと考え、上奏して言った。「烏孫は大国で、弓を引く兵(へい)十万を擁します。それゆえ武帝(ぶてい)は公主(皇族の娘)を(烏孫王に)嫁がせ〔注:このことは第二十一巻・元封(げんぽう)六年の記事に見える〕、孝宣帝(こうせんてい)の代になって、ついにその力を役立てることができました〔注:このことは第二十四巻・本始(ほんし)三年の記事に見える〕。いま使者を遣わして招き慰撫(いぶ)し、ともに力を合わせるのがよろしいでしょう」。帝はこれを受け入れた。

五年
春，二月，庚辰朔，日有食之；詔舉直言極諫。
荊、豫諸郡兵討漊中蠻，破之。
夏，五月，辛亥，詔曰：「朕思遲直士，側席異聞，其先至者，各已發憤吐懣，略聞子大夫之志矣。皆欲置於左右，顧問省納。建武詔書又曰：『堯試臣以職，不直以言語筆札。』今外官多曠，並可以補任。」
戊辰，太傅趙熹薨。
班超欲遂平西域，上疏請兵曰：「臣竊見先帝欲開西域，故北擊匈奴，西使外國，鄯善、于窴卽時向化，今拘彌、莎車、疏勒、月氏、烏孫、康居復願歸附，欲共幷力，破滅龜茲，平通漢道。若得龜茲，則西域未服者百分之一耳。前世議者皆曰：『取三十六國，號爲斷匈奴右臂。』今西域諸國，自日之所入，莫不向化，大小欣欣，貢奉不絕，唯延耆、龜茲獨未服從。臣前與官屬三十六人奉使絕域，備遭艱戹，自孤守疏勒，於今五載，胡夷情數，臣頗識之，問其城郭小大，皆言倚漢與依天等。以是效之，則葱領可通，龜茲可伐。今宜拜龜茲侍子白霸爲其國王，以步騎數百送之，與諸國連兵，歲月之間，龜茲可禽。以夷狄攻夷狄，計之善者也！臣見莎車、疏勒田地肥廣，草牧饒衍，不比敦煌、鄯善間也，兵可不費中國而糧食自足。且姑墨、溫宿二王，特爲龜茲所置，旣非其種，更相厭苦，其勢必有降者；若二國來降，則龜茲自破。願下臣章，參考行事，誠有萬分，死復何恨！臣超區區特蒙神靈，竊冀未便僵仆，目見西域平定，陛下舉萬年之觴，薦勳祖廟，布大喜於天下。」書奏，帝知其功可成，議欲給兵。平陵徐幹上疏，願奮身佐超，帝以幹爲假司馬，將弛刑及義從千人就超。
先是莎車以爲漢兵不出，遂降於龜茲，而疏勒都尉番辰亦叛。會徐幹適至，超遂與幹擊番辰，大破之，斬首千餘級。欲進攻龜茲，以烏孫兵強，宜因其力，乃上言：「烏孫大國，控弦十萬，故武帝妻以公主，至孝宣帝卒得其用，今可遣使招慰，與共合力。」帝納之。
