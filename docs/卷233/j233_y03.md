# 卷233 唐紀四十九 — 德宗神武聖文皇帝八五年

①春、二月、丁亥、韋皋は異牟尋に書状を送って言った——「回鶻はたびたび天子を助けてともに吐蕃を滅ぼしたいと申し出ています。王が早く肚を決めなければ、ある日回鶻に先を越されてしまい、そうなれば王の代々の功名も無駄に捨てることになりましょう。それに雲南は長く吐蕃に辱められてきたのです。今この機に大国の勢いに依って怨みを報い恥をそそがなければ、後悔しても追いつきません」。

②戊戌、横海留後の程懐直を滄州観察使とした。懐直は弓高・景城を分けて景州を置きたいと請い〔注:景城県はもと滄州に属し、武徳四年に瀛州、貞観元年に滄州、大暦七年に瀛州に属した。横海はおそらく朱滔の敗北によってこれを取り戻して領有し、のちほどなく瀛州に属した。弓高は漢の古い県で、魏・晋のときに廃されて省かれ、隋が漢の鬲県の地に弓高県を置き、唐では滄州に属した〕、あわせて刺史は朝廷から任命してほしいと願い出た。上は喜んで「三十年このかた、こんなことはなかった」と言い、そこで員外郎の徐伸を景州刺史とした。

③中書侍郎・同平章事の李泌は、もう一人宰相を任命してほしいとたびたび願い出た。上は戸部侍郎の班宏を用いようとしたが、泌は「宏は清廉で筋を通しますが、性分として物事が滞りがちです」と言い、竇参は物わかりが早く敏捷で度支・塩鉄を兼ねさせられる、董晋は方正で門下省を任せられる、と薦めた。上はどちらも不可とした。参は竇誕の玄孫である〔注:竇誕は武徳年間に斉王元吉に幷州を棄てるよう勧めた人物である〕。当時は御史中丞兼戸部侍郎、晋は太常卿であった。ここに至って泌の病が重くなり、あらためてこの二人を薦めた。庚子、董晋を門下侍郎、竇参を中書侍郎兼度支転運使とし、ともに同平章事とした。班宏は尚書とし、これまでどおり度支転運副使を兼ねさせた。

参の人となりは剛毅で押しが強く、きびしく角が立ち、学問はないが権謀に長けていた。奏上のたび、ほかの宰相たちが退出すると参だけが後に残り、度支の件を申し上げるためと称して、実際には大政を独り占めにし、身内や与党を多く要職に据えて自分の耳目とした。董晋は席を埋めているだけであった。ただし晋は重々しく慎み深い人で、上の前で言ったことを人に漏らしたことがなかった。子弟がそれを尋ねると、晋は「宰相の力量を知りたければ、天下が安らかかどうかを見よ。上の前で謀り議したことなど、語るに足らぬ」と言った〔注:『考異』にいう。韓愈が作った「晋行状」に「宰相の位にあること五年、上の前で奏したことはみな二帝三王の道であり、秦・漢以降のことは口にしなかった。退出して帰っても、上に申し上げたことを人に語ったことがない。子弟がひそかに問うと、公は『宰相の職は天下の安危にかかわる。宰相が有能かどうかは見ればわかる。宰相の能否を知りたければ、そのように見ればよい。およそ上の前で謀り議したことなど、語るに足らぬ』と言った。だからその事跡はついに世に聞こえなかった」とある。愈が行状を作るのだから、必ず美点を掲げて欠点を覆うはずだが、宰相であった時期の事をこれだけしか叙べていないのだから、彼が事なかれで黙々と席を埋めていたことは知れる。とはいえその重々しい慎み深さもまた称するに足る。今はおおむね「行状」を採った〕。

三月、甲辰、李泌が薨じた。泌は謀略があったが、神仙のあやしげな話を好んで語ったので、世間から軽んじられた〔注:『考異』にいう。『国史補』に「李泌が宰相となると、大言壮語を自任し、いつも客の前で家人に急いで掃除をせよ、今夜は洪崖先生が泊まりに来るぞ、と言いつけた。ある人が美酒一樽を贈ってきたとき、たまたま客が来ると、『麻姑が酒を送ってくれた。君と一緒に傾けよう』と言った。飲み終わらぬうちに門番が『某侍郎が樽を取りに来ました』と告げると、泌は返させたが、少しも恥じる色がなかった」とある。『旧唐書・泌伝』には「徳宗は即位した当初、巫祝や怪しげな話をする者をひどく嫌っていた。建中の末に賊軍が内地を塞ぎ、桑道茂が奉天の城について説を立てたころから、上はしだいに日取りや禁忌を気にするようになった。かねて泌が鬼神の道に長けていると聞いていたので、外から召し返して重く用いた。当時の世論はこれを快く思わなかった。宰相の位にあっては、その時々に応じて調子を合わせるばかりで、称するに足るものがない。また顧況のような軽薄な連中と付き合い、何かにつけて朝廷の士から笑われ、そしりを受けた。泌は奔放で弁が立ち、大言を好み、宮中に出入りするようになってからは、しばしば権勢家に妬まれたが、いつも知恵で難を免れた。ついには縦横の弁論で聖主を悟らせ、宰相の位に登った。はじめ泌が江南に流されていたころ、柳渾・顧況と世俗を離れた交わりを結び、詩を吟じて自ら楽しんでいた。渾が先に世に出たので、泌もまた朝廷に官を得ることができた。況は蘇州の人である」とある。思うに泌はあやしげで神仙談を好んだとはいえ、その知略は実に人並みを超えるものがあった。粛宗・代宗を助けて両京を回復し、宰相の位を受けずに去ったこと、代宗・順宗が東宮にあったときいずれも泌のおかげで安泰でいられたことなど、これは大節として重んじるに足る。『旧伝』はこれをけなしすぎである。『家伝』は彼の子の手になるもので、すべてを信じるのは難しいとはいえ、すべて信じないでよいはずもない。今は信じられるものを択んで残しておく〕。

④はじめ、上は李懐光の功を思って、その子の一人を赦してやりたいと考えたが、子孫はみなすでに誅に伏していた〔注:事は二百三十二巻・貞元元年に見える〕。戊辰、詔して懐光の外孫の燕八八を懐光の跡継ぎとし、李承緒という姓名を賜い、左衛率冑曹参軍に任じ、銭千緡を与えて、懐光の妻の王氏を養わせ、その墓の祀りを守らせた。

⑤冬、十月、韋皋は将の曹有道を遣わし、兵を率いて東蛮・両林蛮とともに、吐蕃の青海・臘城の二節度と巂州の臺登谷で戦わせ〔注:臺登は漢の県で、唐では巂州に属した〕、大いにこれを破った。斬首二千級、崖から落ちた者や溺れ死んだ者は数えきれず、その大兵馬使の乞蔵遮遮を殺した。乞蔵遮遮は敵方の勇将であり、彼が死んでからは、皋が攻める城や柵で落ちないものはなくなり、数年のうちに巂州の領域をことごとく回復した。

⑥易定節度使の張孝忠が兵を起こして蔚州を襲い、人や家畜を駆り立てて掠め取った。詔書で責められると、十日あまりで鎮に還った。

⑦瓊州は乾封年間に山賊に陥とされていたが〔注:瓊州は海中の大きな島の上にあり、島の中に黎母山があって黎人が住み、朝廷に税を納めない。いわゆる山賊とは、おそらくこの黎人である。宋白がいう。瓊州の北十五里は果てしない大海で、大船を出し、西南の風に乗れば帆走三日三夜で崖山門という地に着き、江に入って一日で新会県に至る。風がよければ十日で広州に着く〕、ここに至って嶺南節度使の李復が判官の姜孟京と崖州刺史の張少遷を遣わし、これを攻め落とした。

⑧十二月、庚午、回鶻の天親可汗が薨じたと聞き、戊寅、鴻臚卿の郭鋒を遣わして、その子を登里羅没密施俱録忠貞毗伽可汗に册命した。これより先、安西・北庭はいずれも回鶻に道を借りて奏事していたので〔注:吐蕃に阻まれて河・隴の路が通れないため、回鶻に道を借りて奏上を通したのである〕、回鶻と連携して和を保っていた。北庭はとりわけ回鶻に近く、回鶻の取り立てには際限がなかった。また沙陀の六千余帳が北庭と寄り合って暮らしていた〔注:沙陀は西突厥の別部で処月種である。金娑山の南、蒲類海の東に住み、そこに沙陀という大きな砂漠があるので、みずから沙陀と号した〕。三葛祿・白服突厥がみな回鶻に附くようになると〔注:三葛祿とは葛邏祿の三部である。一を謀剌、二を婆匐、三を踏実力といい、北庭の西北、金山の西にある。「白服突厥」を『新唐書』は「白眼突厥」に作る〕、回鶻はたびたびこれを侵し掠めた。吐蕃は葛祿・白服の衆を頼みにして北庭を攻め、回鶻の大相の頡干迦斯が兵を率いてこれを救った。

⑨雲南は吐蕃に二心を抱いてはいたが、まだあえて表立って絶交はしなかった。壬辰、韋皋はふたたび書状を送ってこれを招き諭した。

五年
春，二月，丁亥，韋皋遺異牟書，稱︰「回鶻屢請佐天子共滅吐蕃，王不早定計，一旦爲回鶻所先，則王累代功名虛棄矣。且雲南久爲吐蕃屈辱，今不乘此時依大國之勢以復怨雪恥，後悔無及。」
戊戌，以橫海留後程懷直爲滄州觀察使。懷直請分弓高、景城爲景州，仍請朝廷除刺史。上喜曰︰「三十年無此事矣！」乃以員外郎徐伸爲景州刺史。
中書侍郎、同平章事李泌屢乞更命相。上欲用戶部侍郎班宏，泌言宏雖清強而性多凝滯，乃薦竇參通敏，可兼度支鹽鐵；董晉方正，可處門下。上皆以爲不可。參，誕之玄孫也，時爲御史中丞兼戶部侍郎；晉爲太常卿。至是泌疾甚，復薦二人。庚子，以董晉爲門下侍郎，竇參爲中書侍郎兼度支轉運使，並同平章事。以班宏爲尚書，依前度支轉運副使。
參爲人剛果峭刻，無學術，多權數，每奏事，諸相出，參獨居後，以奏度支事爲辭，實專大政，多引親黨置要地，使爲耳目；董晉充位而已。然晉爲人重愼，所言於上前者未嘗泄於人，子弟或問之，晉曰︰「欲知宰相能否，視天下安危。所謀議於上前者，不足道也。」
三月，甲辰，李泌薨。泌有謀略而好談神仙詭誕，故爲世所輕。
初，上思李懷光之功，欲宥其一子，而子孫皆已伏誅；戊辰，詔以懷光外孫燕八八爲懷光後，賜姓名李承緒，除左衞率冑曹參軍，賜錢千緡，使養懷光妻王氏及守其墓祀。
冬，十月，韋皋遣其將曹有道將兵與東蠻、兩林蠻及吐蕃青海、臘城二節度戰于巂州臺登谷，大破之，斬首二千級，投崖及溺死者不可勝數，殺其大兵馬使乞藏遮遮。乞藏遮遮，虜之驍將也，旣死，皋所攻城栅無不下；數年，盡復巂州之境。
易定節度使張孝忠興兵襲蔚州，驅掠人畜；詔書責之，踰旬還鎭。
瓊州自乾封中爲山賊所陷，至是，嶺南節度使李復遣判官姜孟京與崖州刺史張少遷攻拔之。
十二月，庚午，聞回鶻天親可汗薨，戊寅，遣鴻臚卿郭鋒册命其子爲登里羅沒密施俱錄忠貞毗伽可汗。先是，安西、北庭皆假道於回鶻以奏事，故與之連和。北庭去回鶻尤近，誅求無厭，又有沙陀六千餘帳與北庭相依。及三葛祿、白服突厥皆附於回鶻，回鶻數侵掠之。吐蕃因葛祿、白服之衆以攻北庭，回鶻大相頡干迦斯將兵救之。
雲南雖貳於吐蕃，亦未敢顯與之絕。壬辰，韋皋復以書招諭之。
